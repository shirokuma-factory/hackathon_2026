# 素材とデータの権利の一覧（2026-11-07）

ハッカソンの規定「使う権利のないコード・データ・素材を使った作品は失格」に照らして、公開リポジトリとデモ動画の素材を洗い出した記録です。調べたのは researcher（Opus）と本線で、一次資料のページを開いて確かめています。法的な判断ではありません。

記号: ○ 守れている / △ 表示が足りない・記録がない・条件しだいで問題になる / × 問題がある / 未確認 は一次資料で確かめられなかったもの。× は見つかりませんでした。
