# 地図データと利用条件の調査（2026-11-03）

前提: 背景地図は OpenStreetMap（以下 OSM）にします。用途はすべて非商用です（ハッカソンの提出物とデモ動画）。商用と非商用で条件が変わるものは表に書き分けました。出典はすべて 2026-11-03 に開いて確かめました。データファイルはダウンロードしていません。

記号: ○ = 使える（条件は右の列）、△ = 条件付き・要確認、× = 使えない

## 次の一手

1. 境界は japan-topography の `s0010` の GeoJSON（市区町村 8.8 MB、都道府県 2.4 MB）を使い、出典を画面とリポジトリに書きます。
2. 距離は OSRM 公開デモに 1 秒 1 件で 1 回だけ問い合わせ、結果を保存します。約 1,700 件で約 30 分です（仮定: 出発地は 1 か所）。保存したファイルには ODbL を明記します。
3. 背景は OSM 公式タイルを pydeck の TileLayer で読みます。動画の収録では、同じ範囲を何度も拡大縮小して大量のタイルを取らないようにします。

## a. OSM タイル

| 観点 | 内容 | 出典 |
|---|---|---|
| URL | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | Raster tile providers（OSM Wiki） |
| 出典表示 | 地図上に明示。「© OpenStreetMap contributors」が典型。UI の下や切り替えの奥、画面外に隠さない | Tile Usage Policy |
| 表示文の指針 | 「OpenStreetMap」と openstreetmap.org/copyright へのリンク。旧来の「© OpenStreetMap contributors」も可 | Attribution Guidelines |
| User-Agent / Referer | ブラウザは正しい Referer を送る。Referer を止める Referrer-Policy を設定しない。アプリは固有の User-Agent。python-requests などの既定値は遮断 | Tile Usage Policy |
| 上限 | 数値の上限なし。「heavy or inappropriate use」は遮断対象。保証なし（best-effort） | Tile Usage Policy |
| 禁止 | 一括取得（先読み、タイルの保存、z14 以上の広範囲の自動走査、ボットによる強制描画）、オフライン利用 | Tile Usage Policy |
| キャッシュ | Cache-Control などに従う。読めない場合は 7 日以上保持 | Tile Usage Policy |
| 打ち切り | 「access may be withdrawn at any point」。商用や寄付を募るサービスは特に対象 | Tile Usage Policy |
| デモ・録画 | ポリシーに記載なし。指針では動画の場合、地図が主要素なら地図の隅と終わりのクレジット（または概要欄）に表示し、openstreetmap.org/copyright を含める | Attribution Guidelines |
| 静止画・スクリーンショット | 対話地図と同様に表示。PDF や印刷では URL を印字 | Attribution Guidelines |

判断: Streamlit の画面で pydeck（deck.gl）の TileLayer がブラウザから直接タイルを取るので、Referer は自動で付きます。非商用で利用者は自分 1 人なので、ポリシーの範囲に収まると判断しました。
