## 本線の判断

調査をもとに次のように決めました。

- 既存の計算（佐川・日本通運・JITBOX・標準的運賃）、試験 185 件、撮影の道具、validator は残して使います。
- 見積依頼文・見積回答の比較・保存は、地図の画面から進める後半の操作として残します。
- 地図データ、道路距離、運賃表の利用条件は、調べてから決めます。

### 地図の作り

| 層 | 使うもの | 条件 |
|---|---|---|
| 背景 | OSM 公式タイル（pydeck の TileLayer でブラウザから読む） | 右下に「© OpenStreetMap contributors」を常に出す。先読み・一括取得はしない |
| 市区町村の色分け | japan-topography の市区町村 GeoJSON（N03 の 2021 年版を 1% に簡略化、8.8 MB） | 国交省の指定する出典表記を画面と README に出す |
| 代表点 | 市区町村の多角形の重心を計算する | 追加のダウンロードをしない。島がある市町村は重心が海に出ることがあるので、道路距離では最寄りの道路に寄せる |
| 道路距離と運転時間 | OSRM 公開デモの table サービスに、出発地ごとに約 18 回だけ問い合わせて保存する | 1 秒 1 件を守る。保存した表は ODbL と出典を付ける |

### 色分けに使う値

- 全国の市区町村について出せるのは、道路距離、運転時間、標準的運賃（告示なので著作権の対象外）の目安だけです。
- 標準的運賃は、文字で読めた関東運輸局の距離制運賃だけを使います。そのため、出発地は当面関東の市区町村に限ります。
- 宅配・路線便・カゴ台車の金額は、デモの区間で持っている値だけを、選んだ着地のカードに出します。
- 鉄道と船は運賃表を使えないので、地図には駅・港を通る経路の線と「問い合わせが必要」だけを出します。
