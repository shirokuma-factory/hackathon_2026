# 自社データの形と記録義務の調査

調査日: 2026-11-04（すべての出典の取得日）。調査者: researcher サブエージェント（Opus）。
対象: 10両以下の運送事業者、中小荷主が自社の運行データを持ち込む機能の前提。求荷求車・マッチング・法務は扱っていません。

## 結論

1. 10両以下の運送事業者でも、全車両について運転者ごとの「業務記録」（地点・日時・距離、荷待ち30分以上、荷役1時間以上）を1年間残す義務が、2025年4月1日から課されています。アプリが読み込むべき行の単位はこの業務記録です。
2. 9両以下の事業者のデジタコ（デジタル式運行記録計）装着率は41.3%（車両数ベース、2025年度調査）です。小さい会社の半分以上は紙の日報か手入力で、CSV がある前提にはできません。
3. 荷主側は、特定荷主（年9万トン以上）が2026年4月から定期報告で施設ごと・月ごとの荷待ち時間等を分単位で出す義務を負います。積載率は「重量ベースか容積ベースかは事業者が決める」とされ、算定方法が統一されていません。

## 根拠の表

### 1. 記録義務（運送事業者側）

| 記録 | 根拠 | 対象 | 主な項目 | 保存 |
|---|---|---|---|---|
| 点呼記録 | 輸送安全規則 第7条第5項 | 全事業者 | 点呼者・運転者氏名、車両番号、日時、方法、酒気帯び等 | 1年 |
| 業務記録（乗務記録） | 同 第8条第1項 | 全事業者（軽は4輪以上） | 下の別表 | 1年 |
| 貨物の積載状況 | 同 第8条第1項第6号 | 車両総重量8t以上又は最大積載量5t以上 | 積載状況 | 1年 |
| 荷待ち・荷役等の記録 | 同 第8条第1項第7号・第8号 | 全車両（2025-04-01から。それ以前は8t/5t以上） | 下の別表 | 1年 |
| 運行記録計 | 同 第9条 | 車両総重量7t以上又は最大積載量4t以上、特積み | 瞬間速度、運行距離、運行時間 | 1年 |
| 事故の記録 | 同 第9条の2 | 全事業者 | 氏名、車両、日時、場所、概要 | 3年 |
| 実運送体制管理簿 | 貨物自動車運送事業法 第24条の5、施行規則 第13条の13 | 元請（真荷主から1.5t以上を引き受け、他社に再委託した場合） | 実運送会社名、貨物の内容と区間、請負階層 | 運送完了から1年 |
| 運送契約の書面の写し | 施行規則（法第12条関係） | 真荷主と一般貨物事業者 | 書面の写し | 1年 |

業務記録（第8条第1項）の項目。現行条文（2026-04-01施行版）をe-Gov APIで取得して確かめました。

| 号 | 項目 | アプリでの使い道 |
|---|---|---|
| 1 | 運転者等の氏名 | 運転者ID |
| 2 | 自動車登録番号等 | 車両ID |
| 3 | 業務の開始・終了の地点と日時、主な経過地点、業務に従事した距離 | 区間、走行キロ |
| 4 | 交替の地点と日時 | 補助 |
| 5 | 休憩・睡眠の地点と日時 | 拘束時間 |
| 6 | 貨物の積載状況（8t/5t以上のみ） | 積載率（小型車は記録義務なし） |
| 7 | 荷主都合の待機: 集貨地点等、指定到着日時、到着日時、荷役の開始・終了日時、附帯業務の開始・終了日時、出発日時 | 荷待ち時間 |
| 8 | 荷役作業等: 地点、開始・終了日時、内容、荷主の確認の有無（契約書に全て明記されていれば1時間以上の場合のみ） | 荷役時間 |
| 9 | 事故・著しい遅延の概要と原因 | 補助 |
| 10 | 第9条の3第3項の指示の内容 | 補助 |

- 第8条第2項により、運行記録計で記録した項目はその記録で代えられ、残りの項目を付記します。デジタコの出力と手書きの付記が混在するのは条文上の前提です。
- 「荷主都合で30分以上待機した場合」という基準は条文にはなく、近畿運輸局のチラシに「従来と同様に、荷主都合により３０分以上待機した時は記録対象」と書かれています（下限の根拠になる告示・通達の本文は未確認）。
- 第6号の積載状況は8t/5t以上だけが対象のため、2t・4t車中心の小さな会社では積載量の列が空になりやすいです（条文からの推論）。

- ガイドブックの回答者は協会の理事・青年部会で、平均より規模が大きい会社に偏っている可能性があります（推定）。2025年度調査の9両以下41.3%との差もこの偏りで説明できるかもしれません。

### 3. 荷主側の義務（物流効率化法）

| 項目 | 内容 | 出典 |
|---|---|---|
| 施行 | 2025年4月 全荷主に努力義務。2026年4月 特定事業者に中長期計画・定期報告を義務化 | 手引書 特定荷主編 第1.1版 |
| 特定荷主の基準 | 年度の取扱貨物重量 9万トン以上（第一種・第二種それぞれ） | 同 |
| 重量の算定 | 実測が難しければ車両台数×積載量、売上額や容積からの換算も可 | 同 |
| 積載効率の定義 | 積載効率＝積載率×実車率。積載率＝積載重量/最大積載重量。貨物によっては容積ベースもある | 同 |
| 積載率の把握方法 | 重量ベースか容積ベースかは事業者ごとに設定 | 同 |
| 荷待ち時間の算定 | 指示時間帯がなければ到着（受付）時刻から荷役開始まで。あれば指示時刻から荷役開始まで。運送側の遅着による待ちは含めない | 同 |
| 定期報告の数値欄 | Ⅳで施設ごとに月別平均の荷待ち時間・荷役等時間を分単位で記入。サンプリング可（年度の取扱重量の半分程度以上を把握できる施設を選ぶ） | 同 |
| 定期報告のその他 | Ⅱ 判断基準の遵守状況はチェック形式、Ⅲ 追加の取組は自由記載 | 同 |
| 国の目標 | 1運行の荷待ち・荷役等時間を2時間以内、全体の車両で積載効率44%、5割の車両で50%（2028年度まで＝2029年3月末） | 国交省 物流効率化法Q&A |

- 定期報告で積載効率の数値記入が求められているかは、手引書の構成（Ⅱ〜Ⅳ）からは読み取れませんでした。未確認です。
- 荷主が荷待ち時間を自分で測れない場合は運送事業者に確認することが想定されています（近畿運輸局チラシ）。運送事業者の業務記録が荷主の報告の材料になります。

### 5. データの乱れ

| 事実 | 出典 |
|---|---|
| 積載率は「伝票申告ベースで算出されることが一般的」で、実重量との乖離や低積載路線の特定が難しい | 日本通運・アドヴィックス・スマートドライブ 2026-03-24 発表 |
| 配車の最適計算には「物流条件を分類・整理し、データとして整えることが大切」 | 国交省 ITツール活用ガイドブック |
| 実車率＝実車キロ÷走行キロ×100、積載効率＝輸送トンキロ÷能力トンキロ×100 | 国交省 自動車輸送統計 用語の解説 |
| 積載率の重量・容積の選択は事業者任せ | 手引書 特定荷主編 |
| 運行計画・出荷情報の標準化として「物流情報標準ガイドライン」ver.3.00（2025-02-07） | 国交省 報道発表 |

- 表記ゆれ（社名・住所）や欠損の割合を数字で示した公的資料は見つかりませんでした。
- 統計の積載効率はトンキロ比、物流効率化法の積載効率は積載率×実車率と、2つの定義が並存しています。アプリでは使う式を画面に明記する必要があります（判断）。

## 確認できなかったこと

- デジタコ各社（矢崎エナジーシステム、デンソー、トランストロン、パイオニア）の CSV の列定義。公開資料は見つかりませんでした。メーカー間の形式統一を議論した国交省資料も見つかりませんでした。
- 小さな運送事業者で紙・Excel・システムを使う割合の数字（全ト協・国交省とも）。
- 30分の下限を定めた告示・通達の本文。
- 定期報告に積載効率の数値欄があるか。
- SmartDrive Fleet、トラックマネージャー、ロジこんぱすの公式価格。
