# 3D モデルと道具の接続の設計

2026年11月4日。作成者の指示: アプリは Web アプリとして動くことが前提。Blender や Unity で表現を支える部分を作りたい。様々な道具を MCP などで Claude とどう接続し、Claude をどう生かしているかが評価の観点になるので、その情報も残す。

## 本線の判断: 道具ごとの役割

| 道具 | Claude との接続 | 作るもの | Web アプリでの使い方 |
|---|---|---|---|
| Blender 5.2 | Blender MCP（対話の Blender に接続し、Python を実行・画面を撮る）。MCP が使えないときは `blender --background` に Claude が書いた bpy の台本を渡す | 低ポリゴンの乗り物 4 種（トラック、貨物列車、フェリー、貨物機）と施設 3 種（物流倉庫、貨物ターミナル、港のガントリー）。glTF（.glb）で書き出し、1 個 200KB 以下を目標 | deck.gl の ScenegraphLayer で地図の上に置き、経路の上を進ませる。拡大したときだけ 3D、引いたときは今の SVG の形に切り替える |
| Unity 6 | Unity MCP（Pipeline） | デモ動画の場面（物流拠点で帰り便のトラックに荷を積む様子などを、Blender のモデルで組んだ 3D の場面）。録画した映像を動画に使う | アプリには入れない（Web アプリを重くしないため）。動画の素材だけ |
| ComfyUI | local-ai MCP（`comfy_run_workflow`） | 動画の説明の静止画・背景、モデルの質感の下絵 | 使うのは動画とモデルの質感の下絵だけ |
| DaVinci Resolve | DaVinci Resolve MCP | デモ動画の編集、字幕、書き出し | なし |
| Ollama | local-ai MCP | 大量の下書き・分類（外に出せないデータ） | なし |
| 内蔵ブラウザ・Edge ヘッドレス | Claude の browser 道具、`tools/capture_web.py` | 画面の確認、1920×1080 の証拠の画面写真 | なし |
| サブエージェント | Agent 道具（coder＝Sonnet、reviewer・researcher＝Opus） | 実装、調査、独立の検証 | なし |

## 進め方

1. まず全部入りの版を作る（3D の乗り物と施設、市区町村の帰り便の偏り、物流が集まる地域と施設）。
2. そのあと、機能と見た目の質を保ったまま軽くする（データの分割と遅延読み込み、簡略化、3D の描き分け）。軽くする前と後で、読み込みの大きさと描画の速さを測って記録する。
3. 生成物（3D モデル、画像）は、軽くする前に一覧画像で作成者に見せる。一覧は原案を一番上に置く。

## 確かめたこと（2026-11-04）

| 項目 | 結果 |
|---|---|
| Blender 5.2.2 を `--background` で起動 | ○ 約 5 秒。glTF の書き出しあり |
| Blender MCP（対話の Blender に接続） | × Blender が起動していないため接続できない（127.0.0.1:9876） |
| Blender MCP の画面なしの実行 | × 120 秒で時間切れ。原因は未確認 |
| Unity MCP | × Pipeline のサーバーを持つ Unity Editor が起動していない |
| DaVinci Resolve MCP | △ 接続はできる。Resolve は起動していない |

## その後の結果（2026-11-05 に追記）
