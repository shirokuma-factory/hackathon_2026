# 3D 素材とアニメーションの計画

2026年11月4日。作成者の指示「ローカルマシンの力を使って、アニメーションやデザインの基礎のセットを考えつく限り作り、アプリに組み込む」を受けて決めた内容です。

## 決めたこと

| 段 | 内容 | 作るところ | 道具 |
|---|---|---|---|
| 1-A | 船のコンテナの色を灰色と水色に直す。クレーン、RTG、ウイング車の開閉を glTF のアニメーションにする | assets3d/source/build_models.py | Blender（画面なし） |
| 1-B | 基礎の小物セット（パレット、カゴ台車、宅配サイズの箱、フォークリフト、ULD、20ft・31ft・冷蔵コンテナ、コンテナ車など） | assets3d/source/build_props.py | Blender（画面なし） |
| 1-C | 地図に 3D モデルを載せる。拡大したときだけ 3D、引いたときは今の印。乗り物は進行方向を向かせる | web/models3d.js ほか | deck.gl ScenegraphLayer |
| 1-D | 積付けの 3D 表示。荷物の寸法と個数から、荷台・コンテナ・ボックスへの積み方を Python で決め、画面で立体に見せる | src/shipcompare/loadplan.py、web/loadview.js | Python、deck.gl |
| 2 | モデルから地図用の印と凡例用の画像を描き出す。デモ動画用に回転する映像を GPU で描く。デモ用の自動で進む案内 | 1 の後 | Blender Cycles（RTX 5080） |

## 理由

- 1-A〜1-D は触るファイルが重ならないため、同時に進めます。
- 積付けの判定は金額と同じく決定的な関数で行い、画面は結果を描くだけにします（SPEC の約束）。
- Unity は MCP がまだつながっていないため、今回はデモ動画の場面だけに使う予定のままにします。
- 生成物は一覧画像を作成者が確認してから、軽くする段に進みます。
