# デモ動画の採点基準（v1、2026-11-07）

この基準で AI の採点者が付けた点は、審査結果の予測ではありません。作成者の言葉と公式の審査基準から、直す所を見つけるための物差しです。

## 材料

- 公式の審査基準（`docs/plan/2026-11-03_審査基準と計画の照合.md`）: インパクト 30% / デモ 25% / Claude の活用 25% / 深さと実行力 20%。動画は 3 分以内・日本語・実際に動いているところが中心。
- 作成者の言葉（11/6〜11/7）: 「テレビ CM（約 100 万ドル級）の仕上がり」「100 点を目指す」、指摘の全件は `docs/video/2026-11-07_r10_確認表.md` と `docs/DEVLOG.md` の 11/7 の節。
- 提出の形: YouTube の限定公開。1920×1080 の mp4。

## 配点（100 点）

| 観点 | 配点 | 満点の条件（確かめ方） |
|---|---:|---|
| A 課題が伝わる | 20 | 冒頭 20 秒で「誰が・何に困っていて・なぜ今か」が 1 文で言える（文字起こし）。数字は最新の一次資料（出典の行） |
| B 解決が伝わる | 15 | 「Backfull で何ができるか」4 つが名前と画面で示され、物流を知らない人でも何に使うか分かる（コマと文字起こし） |
| C デモの見え方 | 15 | アプリの画面は Mac 風の窓の中で、画面全体が見え、左右に出し分け、字幕は反対側。寄りや速いスクロールで酔わない（コマ） |
| D 声と画面の対応 | 15 | 図・字幕・場面の切り替えが、その言葉を言う 0.3 秒以内に出る。言っていない数字が画面に出ない（文字起こしの時刻とコマ） |
| E 間と音 | 10 | 問題の提示・数字・締めの前後に間がある。章や場面の効果音が鳴り終わる前に話し始めない。冒頭のフックは BGM なし、締めは別の曲（測った値） |
| F 映像の仕上がり（CM 級） | 10 | 黒い画面・意図しない重なり・崩れた文字・小さすぎる文字がない。外国の事務所や外国人のモデルなど、設定に合わない素材がない（コマ） |
| G Claude の活用 | 10 | 製品の中の Claude（Haiku・Sonnet・Opus の役割分担）と、作る過程の Claude Code（役割を分けたエージェント、Blender・ComfyUI・Resolve・ElevenLabs・Suno を動かした）が、事実どおりに示される |
| H 締めと記憶に残るか | 5 | 締めの一文とロゴで終わり、もう一度見たくなる。3 分以内 |

## 減点（配点とは別）

| 内容 | 減点 |
|---|---:|
| 一次資料と食い違う数字、古い版の数字を今の値として出す | −10 / 件 |
| 出典の無い数字、架空の例を架空と示さない | −5 / 件 |
| 黒い画面（0.5 秒以上、意図しない） | −5 / か所 |
| 言っていない数字・項目が図に出る、図と声のずれ 0.5 秒以上 | −3 / か所 |
| 字幕・図・見出しの重なり（読めなくなるもの） | −3 / か所 |
| 3 分を超える | −20 |
| 言い過ぎ（できないことをできると言う、試算を事実と言う） | −5 / 件 |
| 実在の会社の運賃・空き・名前 | −10 / 件 |

## 採点者に渡すもの

- 動画: `outputs/video/assembly/Backfull_r<N>.mp4`（ffmpeg は `C:/ai/bin/ffmpeg.exe`）
- 見るための材料（毎回作り直す）: `outputs/video/review/r<N>/`
  - `transcript.txt`: 書き出した動画の音を文字に起こした、言葉ごとの時刻
  - `clause_sheets/`: 声の句ごとに、その瞬間のコマ（時刻と句つき）
  - `sec_sheets/`: 1 秒ごとのコマ
  - `audio.txt`: 区間ごとの音量（冒頭・締めの BGM、全体の LUFS）
- 台本: `docs/video/shots_r7.json`、出典の行: `docs/video/sources_r4_map.json`、出典の最新版の調べ: `docs/video/2026-11-07_動画の出典の最新版.md`

採点者は音を聞けない。音は文字起こしと測った値で判断し、聞かないと分からないことは「聞いていない」と書く。

## 出力の形

観点ごとの点と理由、減点、役ごとの納得（○△× と理由）、指摘の表（重大度 P0/P1/P2、区分「実データ / 映像 / 文言」、場所＝秒、起きる状況、根拠）、100 点に届くための直しの順、確信度。結果は `docs/reviews/2026-11-07_デモ動画の採点_r<N>.md`。

## 止めどき

- P0・P1 が 0 件で、残りが P2 だけ。
- 2 回続けて点の差が採点者ごとのぶれ（±6〜7 点）より小さい。
- 残りが作成者しか決められないこと（実在の利用者、公開の URL など）だけ。
