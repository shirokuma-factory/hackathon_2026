# JARTIC 交通量 API の規約と取得方法の要点

取得日: 2026-11-03（ウェブページと公開 PDF を読んだだけです。API は呼んでいません）

## 結論

- 登録も API キーも不要で、使った時点で規約に同意したとみなされます（交通量 API 利用規約 第2条）。
- 交通量 API 利用規約は、取得値を加工して資料やウェブサイトで公表することを前提に、出典の書き方を定めています（第5条）。ただし第4条で、利用条件は JARTIC サイトの利用規約にも従うとされています。JARTIC サイトの利用規約には「複製、改変」「放送、出版」を無断で行ってはならないという条項があり、2つの規約の関係ははっきりしません。
- このため、加工した小さな CSV/JSON を公開リポジトリに置くことと、動画に映すことは △ と判断しました。生値をそのまま再配布することは × 寄りの △ とします。確実にするには JARTIC の問い合わせフォームで確認する必要があります（回答は保証されていません）。
- 1時間値は過去3か月分を検索できます。ただし近畿地方整備局の管内（兵庫を含む）は、CCTV トラカン（CCTV 映像から AI で数える計測器）の値が当面5分値だけです。常設トラカン（路面に設置した常設の計測器）の1時間値が近畿で取れるかどうかは確認できていません。

## 規約の要点

| 項目 | 判定 | 根拠（短い引用） | 出典 |
|---|---|---|---|
| 同意の方法 | ○ 利用した時点で同意したとみなす。クリックや登録はない | 「本機能を利用した場合、本規約に同意したものとみなします」 | [A] 第2条 |
| API キー・登録 | ○ 不要（記載なし） | 「無料でご利用いただけますが…規約への同意が予め必要です」 | [C] |
| 利用料 | ○ 無料（通信費は利用者の負担） | 「本機能を無償で利用することができます」 | [A] 第3条4 |
| 大量アクセス | × 禁止。回数の上限は書かれていない | 「短時間における大量のアクセス」 | [A] 第6条1(2) |
| アクセス制限 | △ 負荷に応じて運用者が制限することがある | 「負荷状況に応じてアクセス制限をかけることがあります」 | [A] 第3条3 |
| 応答の大きさ | △ 約 6MB（6,291,556 バイト）を超えるとエラーになる | 「exceeded maximum allowed payload size」 | [B] 1-5 |
| 取得値を保存し、加工した値を公開リポジトリに置く | △ API 規約は加工した値の公表を想定している。JARTIC サイト規約は無断の複製・改変を禁じている | 「加工して作成」 | [A] 第5条2、第4条、[D] 第2条 |
| 生値の再配布 | △（× 寄り） API 規約に明文がない。JARTIC サイト規約は第三者への無断提供と公衆送信を禁じている | 「無断で第三者に閲覧、表示、提供」 | [D] 第2条 |
| 出典表示（資料・ウェブサイト） | ○ 書き方が決まっている | 下の「出典の書き方」を参照 | [A] 第5条2 |
| 出典表示（アプリ・サービス） | ○ 利用者が使うたびに見える位置に表示する | 下の「出典の書き方」を参照 | [A] 第5条1 |

| 非商用利用 | △ 上の行と同じ扱い | 同上 | [A][D] |
| 参考値の扱い | ○ 参考値であり、国の正式な調査結果ではない | 「参考値であり…正式な交通量の調査結果として提供するものではありません」 | [A] 第3条2 |
| 品質の保証 | × 保証はない。職員による事前のデータ確認もしていない | 「事前に職員によるデータチェック等は実施しておりません」 | [E] 1(4) |
| 予告なしの変更・停止 | △ 起こりうる | 「予告なくコンテンツの変更、提供の停止」 | [A] 第3条1 |
| 禁止事項 | × 運用の妨害、大量アクセス、国民の安全への脅威、第三者への損害、法令違反 | 「本機能の運用を妨害する行為」 | [A] 第6条1 |
| 責任の明記 | △ アプリ等を作って運営する場合は、利用者が一切の責任を負う旨を明記する | 「一切の責任を負う旨を明記する」 | [A] 第8条2 |
| アクセスログの保存 | △ アプリ等でサービスを提供する場合に求められる | 「アクセスログの記録および保存」 | [A] 第8条5 |
| 動画・画面での表示 | △ API 規約は「資料等」の公表を出典付きで認めている。JARTIC サイト規約は「放送、出版」を禁じている。動画に映すことを明示的に扱った条文はない | 「放送、出版、販売を行うこと」 | [A] 第5条2、[D] 第2条 |
| 規約の改定 | △ 告知なしに改定されることがある | 「告知なく改定することがあります」 | [A] 第11条 |

### 出典の書き方（[A] 第5条の記載例をそのまま写したもの）

- 資料・ウェブサイトで公表する場合: 「交通量 API（国土交通省）機能による交通量(参考値)」
- 加工して使う場合: 「国土交通省 API 機能による交通量(参考値)を加工して作成」
- アプリ・サービスで提供する場合: 「このサービスは、交通量 API 機能を使用していますが、サービスの内容は国土交通省によって保証されたものではありません。」

このリポジトリの用途では、地図と動画の両方に「国土交通省 API 機能による交通量(参考値)を加工して作成」を表示します。Web 地図はサービスと見なされる可能性があるため、アプリ用の一文も画面の下に併記します（安全側に倒した判断です）。

### 2つの規約の関係について

- [A] 第4条は「コンテンツの利用条件は、本規約及び…本機能の媒介を行うウェブサイト等に関する規約に準じる」としています。ガイダンスサイトは [D]（JARTIC サイトの利用規約）を「API利用前に必ずお読みください」として載せています。
- [D] は JARTIC サイト（jartic.or.jp）に掲載されたコンテンツを対象とする書き方で、API と jartic-open-traffic.org のどちらにも触れていません（制定 2020-10-21、改定 2021-12-23）。API より前に作られた規約です。
- 別の規約として、JARTIC の「各種情報の提供（オープンデータ）」ページの利用規約 [F] があります。複製、公衆送信、加工、商用利用を認めており、CC BY 4.0（出典を書けば加工・再配布・商用利用を認めるライセンス）と互換です。このページには「交通量データ（国土交通省）」という項目もあります。ただし、ページの該当部分が読み取れず、どのファイルを配っているのか、API の取得値に [F] が適用されるのかは確認できませんでした。
- 判断: このリポジトリでは [A] の第5条に従って出典を書きます。そのうえで、置くのは加工した集計値（地点ごとの時間帯別の大型車台数など）に限り、API の応答そのものはコミットしません。公開前に JARTIC の問い合わせフォームで確認できれば、△ を ○ に変えられます。

## 1時間値の取得方法（[B] 1-2、1-4 より）

| 項目 | 値 |
|---|---|
| 送信先 | `https://api.jartic-open-traffic.org/geoserver`（GET） |
| 方式 | WFS 2.0.0 の GetFeature（地図データを属性付きで返す標準の問い合わせ形式） |
| 常設トラカンの1時間値（様式2） | `typeNames=t_travospublic_measure_1h` |
| CCTV トラカンの1時間値（様式4） | `typeNames=t_travospublic_measure_1h_img` |
| 固定のパラメータ | `service=WFS&version=2.0.0&request=GetFeature&srsName=EPSG:4326&outputFormat=application/json&exceptions=application/json`（CSV がよければ `outputFormat=csv`） |
| 絞り込み（`cql_filter`、AND でつなぐ） | `道路種別='3'`（一般国道、必須）、`時間コード`（必須）、`常時観測点コード`、`BBOX(ジオメトリ,最小経度,最小緯度,最大経度,最大緯度,'EPSG:4326')` |
| 時間コード | `YYYYMMDDhh00`。範囲は `"時間コード">=202610260000 AND "時間コード"<=202611012300` のように書く |
| 検索できる期間 | 1時間値は過去3か月、5分値は過去1か月（[C]） |
| 提供の遅れ | 観測からおよそ20分後（[G]） |
| 応答の上限 | 約 6MB。超えると `Function.ResponseSizeTooLarge` が返る |
| 該当なしの応答 | `"numberMatched":0` の空の FeatureCollection |

仕様書に載っているリクエスト例（様式2）:

```
https://api.jartic-open-traffic.org/geoserver?service=WFS&version=2.0.0&request=GetFeature&typeNames=t_travospublic_measure_1h&srsName=EPSG:4326&outputFormat=application/json&exceptions=application/json&cql_filter=道路種別=3 AND 時間コード=202502100900 AND BBOX(ジオメトリ,139.15,35.141,139.32,35.56,'EPSG:4326')
```

実際に送るときは `cql_filter` の日本語と空白を URL エンコードします（Python の `requests` に `params` で渡せば自動で行われます）。

### 応答で使う項目

| 用途 | 様式2（常設） | 様式4（CCTV） |
|---|---|---|
| 地点 | `常時観測点コード`、`geometry.coordinates`（MultiPoint、経度・緯度の順） | 同じ |
| 地方 | `地方整備局等番号`（83 関東、85 中部、86 近畿） | 同じ |
| 時刻 | `観測年月日`（YYYYMMDD）、`時間帯`（hhmm） | `観測年月日`、`時間帯`（0〜23 の整数） |
| 上りの大型車 | `上り・大型交通量`（台/時、欠測は空欄） | `上り・大型交通量` |
| 下りの大型車 | `下り・大型交通量` | `下り・大型交通量` |
| 欠測の判定 | `上り・欠測` `下り・欠測`（1 が欠測）、`停電` `ループ異常` `超音波異常` | `上り・5分欠測処理フラグ` など |

上りと下りの定義: 仕様書 1-6 は、上りを路線の終点から起点へ向かう方向としています（同じ節の下りの定義も「終点から起点」と書かれており、仕様書の誤記と見られます）。路線ごとの向きは、国土交通省の「一般交通量調査結果 WEB マップ」の交通調査基本区間番号の下4桁で確かめる方法が紹介されています。

## 3つの区間の観測地点 ID の探し方

観測地点の一覧ファイルは、ガイダンスサイトにも仕様書にも見つかりませんでした。地点 ID（`常時観測点コード`）は API の応答からしか分かりません。次の手順で集めることにしました。

1. ある1時刻（例: 直近の平日 10 時）を指定し、`道路種別='3'` と BBOX で様式2と様式4の両方を取得します。地点ごとに1件ずつ返るので、地点の一覧として使えます。応答が 6MB を超えないよう、BBOX は県単位くらいに分けます。
2. 取得した地点の座標と、リポジトリにある経路線（OSRM の経路）との距離を Python で計算し、300m 以内の地点を候補にします。その中から区間ごとに5〜7地点を選びます。
3. 選んだ地点ごとに `常時観測点コード=… AND 時間コード>=…0000 AND 時間コード<=…2300` で7日分（168 時間）を1回で取得します。20地点なら20回程度で済み、大量アクセスには当たらない量です。リクエストの間は数秒あけます。

区間ごとの BBOX の目安（緯度経度はこちらで地図から読んだ概算で、出典はありません）:

| 区間 | 通る地方（地方整備局等番号） | BBOX の目安（経度・緯度の最小と最大） | 注意 |
|---|---|---|---|
| 兵庫–東京 | 近畿 86、中部 85、関東 83 | 134.6, 34.4 – 139.9, 35.9（県ごとに分割） | 近畿は CCTV の1時間値がない。常設の1時間値があるかは未確認。なければ5分値（過去1か月）を12本足して1時間にする |
| 東京–三重 | 関東 83、中部 85 | 136.0, 34.2 – 139.9, 35.8 | 中部は `開発建設部／都道府県コード` で県が分かる（22 静岡、23 愛知、24 三重） |
| 神奈川–愛知 | 関東 83、中部 85 | 136.7, 34.6 – 139.7, 35.6 | 東京–三重と重なる地点は共有できる |

地図で地点を目で確かめたいときは、国土交通省の道路データプラットフォーム（xROAD、[H]）のビューアを使うよう案内されています。このビューアは今回開いていません。

## 確認できなかったこと

- 仕様書の各 API の表に「認証方式 有」と書かれている一方、ガイダンスサイト、手引き、規約のどれにも API キーや登録の手順が書かれていません。キーなしで応答が返るかは、API を呼んでいないので未確認です。
- 1分あたりや1日あたりの回数の上限は、どこにも数字が書かれていません。
- 近畿の常設トラカンの1時間値（様式2）が取れるかどうか。ガイダンスサイトは「近畿地方整備局の管轄エリアについては…当面5分間交通量のみ」と書いていますが、手引きでは同じ制限が CCTV トラカンに限定されており、書き方が食い違っています。
- JARTIC サイトの利用規約 [D] が API の取得値にどこまで及ぶのか、オープンデータ規約 [F] が API の取得値に適用されるのか。
- オープンデータページの「交通量データ（国土交通省）」で配っているファイルの中身（ページの該当部分を読み取れませんでした）。
