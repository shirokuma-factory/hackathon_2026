## フォルダ

| フォルダ | 中身 |
|---|---|
| `plan/` | 計画・調査・判断の記録（日付つき） |
| `reviews/` | 採点と監査の記録。`*_r1a.md`・`*_r1b.md` は同じ回の 2 人の採点者。`img/` は採点のときの画面写真 |
| `guide/` | 使う人向けの手引き（自社の運行を分析する、部品の使い方） |
| `video/` | デモ動画の脚本・組み立ての表・確認の記録 |
| `submission/` | 提出の準備（プロジェクト概要の下書き、リポジトリの採点基準） |
| `assets/` | 画面写真と図（README から使うものを含む） |

## 採点の記録の名前

| 名前 | 何を採点したか | 採点者 |
|---|---|---|
| `筋書き_第1部`・`第2部` | 使う人の立場での筋書き（文書） | 審査員・利用者の役の Opus |
| `課題解決の検証` | 課題を解くツールか（第 3 部） | 同上 |
| `論理の筋` | 一次資料からの論理（第 4 部） | 同上 |
| `思想と公開版` | 元の思想と公開版の全体（第 5 部） | 同上 |
| `道具の採点` | 物流の人が使える道具か（第 6 部） | 正しさ重視と使いやすさ重視の 2 人 |
| `実務の効き目` | 仕事が減るか（第 7 部） | 運送会社の側と荷主の側の 2 人 |
| `画面の出来` | 画面の印象と誘導（第 8 部） | 審査員と初めて使う人の 2 人 |
| `implementation-audit`・`客観レビュー_Codex`・`総合レビューと100点の受入条件` | 外部の監査（Codex） | Codex。指摘は本線が再現して確かめた |
| `セッション記録の洗い出し_*` | Claude Code の使い方の記録の抜け | Sonnet |
| `セキュリティ診断` | 公開リポジトリと公開版の脆弱性（履歴を含む） | Opus |
