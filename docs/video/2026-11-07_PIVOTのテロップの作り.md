# PIVOT のテロップの作り（2026-11-07 調査）

デモ動画の字幕を作るための調査です。PIVOT のロゴ・名前・配色の組み合わせは使わず、文字組みの一般的な作法だけを参考にします。

## 結論

- スタジオ収録の回では、話した言葉を全部字幕にしていません。見た 40 枚ほどのフレームのうち、字幕が出ていたのは要点の一言を抜き出した強調テロップだけでした。
- 強調テロップは、太いゴシック体を 1 行ごとに別の平らな長方形の箱に載せ、左端をそろえて画面の下 3 分の 1 に置く形です。影も縁取りもありません。
- 章の見出しは画面の左上に、左端に接した帯で常に出しています。番組ごとに帯の色を変えています（紫から青のグラデーション、赤、緑、黄緑の文字に紺など）。
- 私たちの動画では、同じ「1 行 1 箱・左ぞろえ・影なし」の作法を使い、色は紺と白とオレンジの単色にします（下の仕様）。

## 1. 話した言葉の字幕

直接見たこと:

- スタジオの回には、話した言葉を順に流す字幕がありません。字幕のないフレームが大半でした（0jJKm1HpAB8、2s2sgB9NDGM、C9sWHk4GK84 など）。
- 出ているのは、話の要点を抜き出した 1〜2 行の強調テロップです。
  - 位置: 画面の下 3 分の 1。左端は画面の 8〜18% あたりで、中央ぞろえではなく左ぞろえです。2 行の左端はそろっています。
  - 書体: 太いゴシック体（ウエイトはおそらく Bold から Heavy）。字形から書体名は特定できません。
  - 大きさ（6mqmsEYrPZU の 50% のフレームで測定）: 箱の高さ 86px、文字の高さ 63px、行と行の箱の間 8px（720p）。1080p に直すと箱 129px、文字 95px、間 12px（推定）。47texHal-SQ では箱 80px、文字 67px、間 11px（720p）。
  - 色: 白の箱（#FFFFFF）に黒の文字（実測 #000000 付近）が基本です。番組によって、黄の箱に黒文字、黒の箱に白文字、白の箱に赤文字、白の箱にグラデーション文字、グラデーションの箱に白文字があります。
  - 箱: 1 行ごとに別の長方形で、幅は文字の長さに合わせています。角は丸めていません。影・縁取り・透け（半透明）はありません。
  - 行数: 1 行か 2 行。1 行は 10〜18 文字ほどです。
  - 句読点: 行末の「。」「、」は付けていません。疑問の「？」と、語をくくる“ ”は使っています（“髙島屋流”まちづくりは）。
  - 強調: 1 行目と 2 行目で箱の色を入れ替える（白箱と色箱）、または文字の色を変えることで強調しています。太さや大きさを 1 語だけ変える例は見ていません。
- ドキュメンタリー（＆DOCUMENTARY）の回は別の作法でした。明朝体の白文字を箱なしで画面下に置き、名前は「肩書き（小さい字）＋名前（大きい字）」の 2 段です。数字はピンクの極太の文字を画面に大きく出しています。

推定したこと:

- 毎回の全文の字幕を付けないのは、1 時間前後の対談を、見出しと要点だけで追えるようにするためだと考えられます。

## 2. 章の見出しと名前の表示

直接見たこと:

- 章の見出しは、画面の左上に常に出しています。
  - 6mqmsEYrPZU で測った値（720p）: 帯の上端 y=27、高さ 59px、左端は画面の端に接している（x=0）、幅は文字に合わせて 525px。文字の高さ 33px、文字の始まり x=28。1080p に直すと上端 40px、高さ 88px、文字 50px、左の余白 42px（推定）。
  - 帯の色（実測、JPEG のため近い値）: 左 #BD00F0、中 #7242D4、右 #2B85BA の横グラデーション。2s2sgB9NDGM は赤の単色、NsNn2tYiY38 は緑の単色、d7CasigfHFU は青に黄緑の文字です。
  - 形は番組で違います。長方形（多くの回）、右端を斜めに切った平行四辺形（C9sWHk4GK84）、角を丸めた白い枠にグラデーションの縁（47texHal-SQ、XO8PEQ_1cGQ）。
- 画面の右上にはロゴを常に出しています。
- 名前の表示（人物の下に出す肩書きと名前）は、スタジオの回では見たフレームに入っていませんでした。見えたのは次の 2 つです。
  - バスケットボールの回: 写真の左下に、所属・学年と身長・名前を白い太いゴシック体で 2〜3 行。名前の行だけ大きい。箱はなく、うすい影が付いています。
  - ドキュメンタリーの回: 明朝体の白文字で、肩書き（小）と名前（大）の 2 段。
- 動き: XO8PEQ_1cGQ の 75% のフレームに、テロップが出てくる途中が写っていました。紫の縦の棒が先に立ち、その右に文字が半透明で左から右へ出てきています。

推定したこと:

- 出方は、縦の棒を先に置き、文字を左から右へ拭うように出す動き（ワイプ）と考えられます。長さ（秒数）は静止画からは分かりません。

## 3. 数字と図

直接見たこと:

- PIVOT NEWS の回（Uxy4hL6bjMI）: 角を丸めた白い板に、題（明朝体）、その下に 3 列で「灰色の小さいラベル＋太字の数値」（約4,200億ドル／約27か月／月150億ドル超）。3 つ目の数値だけ金色です。下に紺の箱に白文字で結論を 2 行。右下に小さく「筆者試算（2026年10月末時点）」と出典を書いています。
- 創薬の回（DTwZpVH34mg）: 出演者のスライドを全面に出し、紺から水色の 4 段階の色の箱で項目を並べています。出典（論文名）を右下に小さく入れています。
- ドキュメンタリーの回: 「現在1350万円」のように数字をピンクの極太の文字で大きく出しています。

## 4. 色と調子

直接見たこと:

- 白か明るい背景の上に、白い箱と黒の太い文字という組み合わせが中心で、色は帯と強調の 1 か所にだけ使っています。
- 番組ごとに 1 色（紫から青、赤、緑、青緑）を決め、章見出しと強調に同じ色を使っています。
- 影・光彩・立体の装飾は、見たフレームのテロップにはありませんでした。

推定したこと:

- 調子は報道番組に近い、平らで情報を優先した作りです。

## 5. 似せないために避けること

- 紫から青（#BD00F0 から #2B85BA）の横グラデーションを使わない。これが一番 PIVOT らしく見える色です。
- 左上に、画面の端に接した見出しの帯を常に出す形をそのまま使わない。
- 右上に丸い字形のロゴを置かない。
- 「1 行目が白箱、2 行目がグラデーションの箱」の組み合わせを使わない。
- 角丸の白枠に色の縁を付けた見出しを使わない。

1 行ずつ平らな箱に載せる作法、左ぞろえ、影を付けない、行末の句読点を省く、数値にラベルと出典を添える、といった点は、日本の報道・解説番組で広く使われている作法なので、そのまま使います。

## 私たちの字幕の仕様（1920x1080）

こう決めました。PIVOT の測定値は大きさの目安にだけ使い、色と形は別にしています。

### 書体

- Noto Sans JP の 1 書体だけ。強調テロップは Black（900）、見出しと名前は Bold（700）、ラベルは Medium（500）。
- 数字は同じ書体のまま、等幅数字（`font-feature-settings: "tnum"`）。

### 色

| 用途 | 色 |
|---|---|
| 基本の箱 | #FFFFFF |
| 基本の文字 | #141414 |
| 強調の箱（2 行目など） | #12355B（紺） |
| 強調の箱の文字 | #FFFFFF |
| 数字の強調（1 画面に 1 か所） | #E8590C（オレンジ） |
| ラベル・出典 | #6B7280（灰） |

グラデーションは使いません。

### 強調テロップ（話した言葉の要点）

| 項目 | 値 |
|---|---|
| 文字の大きさ | 88px（Black） |
| 箱の高さ | 124px（上下の余白 18px） |
| 箱の左右の余白 | 28px |
| 行と行の箱の間 | 12px |
| 行数 | 1〜2 行、1 行 16 文字まで |
| 位置 | 左ぞろえ。左端 x=160、最後の行の箱の下端 y=990 |
| 影・縁取り | なし（明るい背景で箱が見えにくいときだけ、箱に影 0 4px 16px rgba(0,0,0,0.18)） |
| 角 | 丸めない（0px） |
| 句読点 | 行末の「。」「、」は付けない。「？」は付ける |
| 強調の方法 | 強調したい行だけ紺の箱に白文字。数字を立てたいときは白箱のまま数字だけオレンジ |

全文の字幕は付けず、ナレーション 1 文につき要点を 1 つ出します。

### 章の見出し

| 項目 | 値 |
|---|---|
| 位置 | 左上。左端 x=64、上端 y=56（画面の端には接しない） |
| 形 | 白の箱（高さ 72px、左右の余白 24px）の左に、紺 #12355B の縦の線（幅 8px、高さ 72px） |
| 文字 | Bold 40px、#141414 |
| 出す時間 | 章が始まってから 4 秒だけ出して消す（常に出しておかない） |

### 名前の表示（肩書きと名前）

| 項目 | 値 |
|---|---|
| 位置 | 左下。左端 x=160、名前の行の下端 y=960 |
| 1 段目 | 肩書き。Medium 30px、#FFFFFF、紺の箱（高さ 48px、左右の余白 16px） |
| 2 段目 | 名前。Bold 52px、#141414、白の箱（高さ 80px、左右の余白 24px）。1 段目との間 0px |
| 影 | なし |

### 数字の表示

- 白の板（角丸 16px、左右の余白 64px）に、ラベル（Medium 30px、灰 #6B7280）と数値（Bold 72px、#141414）を縦に組み、3 つまで横に並べる。
- 一番伝えたい数値だけオレンジ #E8590C。
- 板の右下に出典を Medium 22px、灰で入れる。

### 動き

| 段 | 動き | 長さ |
|---|---|---|
| 出る 1 | 箱を左から右へ拭うように広げる（`clip-path` の幅 0 から 100%） | 0.28 秒、ease-out（cubic-bezier(0.2, 0.8, 0.2, 1)） |
| 出る 2 | 文字を左から 16px ずらして不透明にする。箱より 0.08 秒遅らせる | 0.22 秒、ease-out |
| 2 行目 | 1 行目より 0.10 秒遅らせて同じ動き | 同上 |
| 消える | 箱と文字を一緒に透明にする | 0.15 秒、ease-in |
| 最短の表示時間 | 1.6 秒（読み切れる長さ） | |

PIVOT の出方（棒を立ててから文字を拭うように出す）は 1 枚の途中のフレームから推定したもので、長さは分かっていません。上の秒数は私たちが決めた値です。

## 分からなかったこと

- PIVOT が使っている書体の名前。公式の資料は見つかりませんでした。
- テロップの出入りの秒数と、緩急の付け方。静止画しか見ていないため分かりません。
- スタジオの回の名前の表示の形。見たフレームに入っていませんでした。
- テロップの作り方についての PIVOT の公式の解説や制作者のインタビューは見つかりませんでした。デザイナーの求人票には、使う道具として After Effects と Premiere Pro が書かれています。
