- アプリの値（2t 272,610円、4t 312,210円）は計算どおりです（`src/shipcompare/estimate.py` 422〜443行目）。
- 区分の端数の扱いは、告示に書かれていません（告示の「端数処理」は燃料サーチャージの円未満の話です）。200km までの表が 10km 刻みの行なので、端数を次の区分に入れる読み方が自然です。切り捨てて読んでも約26万円で、「約27万円」との差は 9,580円です。
- 地域の表の選び方も告示に書かれていません。今回の例は東京の荷主が東京の運送会社に借りる場面なので、出発地で選んでも営業所で選んでも関東の表になります。適正原価の検討では「営業所の所在地」で地域を決める考え方が議論されています（経団連の意見 2026-10-01 p.5、「営業所の所在地によって地域を特定するのではなく…」という反対意見として出ています）。
- 参考: 国交省の2026年7月の説明資料 PDF p.2 には、関東の表として 2t 200km 50,270円、20km ごと 3,630円、500km 超 9,070円が載っていて、告示第209号と値が違います。この表で計算すると 2t 258,910円、4t 296,080円です。新しい告示は見つからないので、改定前の表を載せたものと考えています（推定。確かめられませんでした）。

### 目安に入っていないもの（告示の定め）

| 費用 | 告示の扱い | 今回の例での大きさ |
|---|---|---|
| 消費税 | 表の額は税抜（アプリも税抜で扱う） | 2t で +27,261円 |
| 高速道路料金 | Ⅷ「有料道路を利用した区間の料金を別に…収受」 | 調べていません。東京〜鹿児島は全区間高速で数万円になるはずです（推定） |
| 燃料サーチャージ | Ⅹ 軽油 120円/L を超えた分を、走行距離 ÷ 燃費 × 上昇額で加算 | 軽油の価格と燃費は運送会社が決めるので出せません |
| 待機時間料・積込料・取卸料 | Ⅴ・Ⅵ 別に収受 | 30分を超える待機があれば 2t で30分ごとに 1,680円 |
| 宿泊費・フェリー代など | Ⅸ 実費 | 1,345km は1人の運転手では2日以上かかるので、宿泊費が出る可能性があります |
| 下請けに出す場合の手数料 | Ⅶ 運賃の10% | 元請が別の会社に頼むときだけ |

- 標準的運賃の表は、帰り荷がない前提（実車率50%、走る距離は片道の2倍）で原価を積んでいます（国交省 2026年7月の資料 PDF p.4「実車率は50％（帰り荷無し）とする」、p.5「帰り荷なしの前提。」「200km×2」）。片道の額で帰りの空車の分まで払う作りです。
- 実際に払われている運賃は、標準的運賃より低いことが多いです。令和6年度の調査では、標準的運賃と同じ水準をおおむね受け取れている運送会社は53%です（同資料 PDF p.2）。

### 272,610円は「国の目安」と言えるか

言えます。条件は「国の標準的運賃（2024年3月告示、関東の表）から出した、税抜・高速代別の目安」と示すことです。アプリの画面は「税抜、高速代は別」と出しています（`web/compare_lite.html` 464行目、`web/find.js` 70行目）。動画では MG5_m の出典行が「貸切は国の標準的運賃からの目安（税抜）」までで、高速代別が抜けています。字幕「借り切ると 約27万円」には何も付いていません。

出す文の案: 「貸切は国の標準的運賃（2024年告示・関東の表）からの目安。税抜、高速代・燃料サーチャージは別」

## 3. 帰り便 95,000円の妥当性

| 見方 | 値 | 種類 |
|---|---|---|
| 作り方 | 2t の目安 272,610円 × 35% = 95,413円 を丸めた値 | コード（`tools/video/build_kago_sample.py` 28行目） |
| 床の広さで割った額（関東 4t） | 荷の床 4.08㎡ ÷ 4t ウイングの床 13.64㎡ = 29.9%。312,210円 × 29.9% = 93,388円、積載率80%で割ると 116,735円 | 私の計算。4t の床は `data/demo/carriers.json` の T7 |
| 同（九州 4t。鹿児島の会社の表） | 279,140円 × 29.9% = 83,496円、80%で割ると 104,371円 | 私の計算 |
| 国の考え方の例 | 個建運賃 =（貸切の運賃）÷（積める量 × 基準積載率） | 告示 Ⅲ（p.9） |
| 帰り便の相場 | 公開された統計や料金表は見つかりませんでした。求荷求車の掲示板（WebKIT など）の成約額は会員の外に出ません | ― |
| 参考: 混載の箱単位の料金 | ヤマトボックスチャーター 神奈川県内のイベント会場 → 鹿児島 1BOX 43,700円（税別、2024年5月、内寸 104×104×170cm・500kg まで） | 企業の料金表。今回の陳列棚（240×60×200cm）は箱に入らない |

- 95,000円は、荷が使う床の割合で 4t の目安を割った額（8.3〜11.7万円）の中に入ります。安すぎる値ではありません。
- 一方で、国とトラック業界は「帰り荷は安くてよい」という扱いをやめる方向です。適正原価の検討では、空で走る距離の分も原価に入れる案が出ています（国交省 2026年8月 資料8 PDF p.6）。2028年6月ごろまでに適正原価を下回る運賃が制限されます（施行日は未定）。「帰り便だから3分の1の値段」と受け取られる言い方は避けた方が安全です。
- 熊本県トラック協会が帰り荷の安値の慣習を見直すよう呼びかけた、という記事（LOGISTICS TODAY 651164）は 404 で開けませんでした。根拠には使っていません。

付ける表示の案:

- MG5_m の出典行: 「貸切は国の標準的運賃からの目安（税抜・高速代別）。帰り便の値段は架空の例で、実際は運送会社が決めます」
- S2 の画面の隅: 「架空の例」
- ナレーション S2 は今のままで構いません。HP の「安く送れます」は #24 のとおり条件を付けてください。

## 4. 架空の配車表の見本の時刻（誤り）

`outputs/video/web_kago/data/own_sample.json`（`tools/video/build_kago_sample.py` で作ったもの）を調べました。

| 項目 | 値 |
|---|---|
| 鹿屋 ↔ 江東の1区間の距離 | 1,363〜1,411km |
| 1区間の所要時間 | 9.2〜10.9時間（例: 10/2 19:00 発 → 10/3 4:20 着、1,387.2km） |
| 平均時速 | 中央値 145km、最大 153km（時刻と距離のある36区間のうち34区間が時速80km超） |
| 1台の月の区間数 | 最多 18区間（約9往復、約25,000km） |

原因は、加古川版（約556km）の時刻を残したまま、地名と距離だけを置き換えたことです（`build_kago_sample.py` の SUBS 表）。高速道路の法定速度は貨物車で時速90〜100kmで、休憩を含む平均で時速145kmは出せません。1人の運転手の運転は2日平均で1日9時間までです（改善基準告示）。1,370km は2日がかりの距離です。

また、確認待ちの例の文「デジタコの走行距離 668.0 km が、OSRM の推定 1381.7 km より 52% 長くなっています」は、668km の方が短いので文が逆になっています。

直し方: 動画の画面に時刻・距離・この文が映るなら、出発と到着の間を約2日（例: 19:00 発 → 翌々日 4:00 着）にして、1台の月の往復を4〜5回に減らして作り直してください。映らないなら直さなくても動画の誤りにはなりませんが、公開リポジトリに残るので直すことを勧めます。

便 T7（`data/demo/carriers.json`）も、11/13 17:00 発 → 11/14 22:30 着（29.5時間）です。1人の運転手で約1,400km を走るには、運転を2日で18時間、平均時速約78km が要ります。画面に出るなら到着を翌々日にするか、「2人乗務」と注記してください（私の計算）。
