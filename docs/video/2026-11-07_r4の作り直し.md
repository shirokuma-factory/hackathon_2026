# デモ動画 r4 の作り直し（2026-11-07）

## 作成者の指摘（11/7 昼）

- ロゴが斜め。まっすぐにして、線が流れるように。
- デモ画面が古いアプリのまま。
- つなぎの間がなく、無機質で抑揚がない。
- 字幕と図に句読点が多い。字幕の黒い帯が質を落としている。改行を読みやすく、強調する所が伝わるように。
- テレビ CM（10 万ドル相当の広告）並みの洗練が必要。自己採点は 20 点（r3 v9）。
- 荷主の例が、なぜ木工所なのか。もっと小さい会社、伝統工芸や新しく事業を立ち上げた人がよい。

## 道具

- `tools/video/build_r4.py`: `docs/video/edl_r3.json`（r3 のタイムラインの書き出し）に、間・差し替え（`tools/video/r4_replace.json`）・区間の当て方（`tools/video/r4_slots.json`）を当てて `docs/video/edl_r4.json` を作る。字幕と BGM も作り直す。読み込み済みのファイルを上書きしないよう、字幕と BGM は毎回時刻の入った名前にする。
- `tools/video/resolve_build_r4.py`: `edl_r4.json` から Resolve に Backfull_r4 を組む（MCP の run_script_unsafe で実行）。

## 荷主の行き先の直し（11/7 13 時、作成者の指摘「空車があるのは帰りなのに、なんで帰りのところじゃないの」critical）

データ（`web/data/market.json`、全国貨物純流動調査 2021 の 3 日間調査、トラック）で、長距離（300km 以上）で帰りが空きやすい区間を差の大きい順に並べると、1 位は「兵庫県→東京都」（行き 37,326t、帰り 3,127t、比 0.084）。空のトラックが走るのは「東京→兵庫」。運送会社（架空 播磨ライン運輸）は兵庫県加古川市。

| 項目 | 直す前 | 直したあと |
|---|---|---|
| 荷主の場所 | 東京都新宿区 | 東京都新宿区（アプリの東京の計算の起点。変えない） |
| 送り先 | 大阪市中央区（帰り便の向きとずれる） | 兵庫県加古川市（運送会社の地元。見本の帰り便 T7 が降ろせる地点） |
| 中身 | 江戸切子の商品と陳列棚 2m40cm・400kg | 同じ。割れ物で、催事の棚と一緒にまとめて運ぶ必要があり、宅配で小分けにしにくく、1 台を借り切るほどでもない |
| ナレーション | 「大阪の百貨店」「関西へ帰る便」 | 「神戸の百貨店」「東京から兵庫へ帰る便」「さっきの兵庫の運送会社の空の帰りのトラック」 |

値段（借り切りと帰り便）は、アプリで計算し直した数字を使う。

撮り直した結果（アプリは変えていない）: 神戸市中央区では、見本の 7 便のうち載せられる便が 0 だった（T7 は降ろせる地点が大阪市中央区・加古川市などで、神戸は入っていない）。そこで送り先を、T7 が降ろせる兵庫県加古川市（運送会社の地元）にした。中身は、播磨が日本酒の産地であることに合わせ「兵庫の酒蔵の催事へ、江戸切子の冷酒グラスと陳列棚（400kg）」。
