# 動く図（モーショングラフィックス）の仕様（2026-11-06）

作成者の依頼: 「motion graphic と animation、字幕もわかりやすくなるように、強調するところなどをしっかり自然な形で」。

アプリの録画の上に重ねる、数字を見せる動く図を 6 つ作る。HTML と CSS のアニメーションで作り、Edge（ヘッドレス）で 1 コマずつ撮って、背景が透明な動画（qtrle の .mov、1920×1080、30fps）にする。

## 道具

- `tools/video/render_motion.py <名前...>`: `docs/video/motion/<名前>.html` を `outputs/video/motion/<名前>.mov` にする。
  - 起動は `tools/capture_web.py` の `edge_page(1920, 1080)` を使う。背景は `Emulation.setDefaultBackgroundColorOverride` で透明にする。
  - コマは実時間で撮らない。`document.getAnimations()` の全部を止め、`currentTime` を 1 コマずつ（1000/30 ms）進めてから `Page.captureScreenshot`（png）で撮る。数を数え上げる表示は、CSS の `@property` を使った整数の変数か、`window.__seek(ms)` を各 HTML に置いて JS で描く（どちらでもよい。`__seek` があればそれを優先して呼ぶ）。
  - 長さは HTML の `<body data-duration="7.5">`（秒）で決める。
  - 撮った png は ffmpeg（`C:/ai/bin/ffmpeg.exe`）で `-c:v qtrle -pix_fmt argb` の .mov にする。確認用に、コマの一覧（`scripts/contact_sheet.py` か、同じように 12 コマを並べたもの）を暗い背景の上に合成した jpg も出す。
- 書体は Noto Sans JP（`docs/video/graphics/common.css` の色の変数を使う。強調は `--warn` の黄、比べる相手は `--hl` の青、悪いほうは `--ng`）。飾りのアイコン、英字の小見出し、色付きの番号の丸は付けない。

## 共通の見た目と動き

- 図は画面の上側の中央、幅 900〜1100px の板（`--panel` を 92% の不透明度、角丸 12px、細い枠 `--line`）。下の 300px は字幕のために空けておく。
- 出るとき: 0.35 秒で、下から 24px 上がりながら不透明に（ease-out）。消えるとき: 最後の 0.3 秒で不透明度を 0 に。
- 数字は 0.8〜1.2 秒で数え上げ（ease-out）、決まったあとは動かない。棒は左から伸びる（0.8 秒、ease-out）。
- 強調は、該当の数字が決まった瞬間に、黄の下線を 0.3 秒で左から引く。点滅、拡大縮小の繰り返し、回転はしない。

## 6 つの図

| 名前 | 長さ（秒） | 内容 |
|---|---:|---|
| MG1 | 7.5 | 見出し「営業用トラックの積載効率」。大きな数字が 0 → 38.97% に数え上がる（0.4〜1.6 秒）。2.5 秒から、下に横棒 2 本: 「実績 38.97%」（灰）と「国の目標 44%」（青、2028 年度）。4.5 秒に、2 本の差に黄の括弧と「約 5 ポイント足りない」。小さな注記「出典: 国土交通省 自動車輸送統計年報 2025年度 / 国の基本的な方針」 |
| MG2 | 6.7 | 見出し「都道府県のあいだの荷の量（2021年の3日間の調査）」。横棒 2 本: 「兵庫県 → 東京都 37,326 t」（青、長い）と「東京都 → 兵庫県 3,127 t」（黄、短い）。数字も数え上げ。3 秒に、短い棒の横に「帰りは約 1/12」。注記「出典: 全国貨物純流動調査 2021」 |
| MG3 | 8.0 | 見出し「播磨ライン運輸 10月の帰り便（架空の見本）」。53 個の小さな四角（9 列×6 行で 53 個）。0.5 秒から順に青で埋まり（1.5 秒で全部）、そのうち 20 個が 2.5 秒から黄の枠だけ（空）に変わる。右に大きく「53 便のうち 20 便が空」、5 秒に「木曜の夜に出た 5 便は、帰りがすべて空」 |
| MG4 | 6.6 | 見出し「荷待ちの損（国の平均に当てた場合）」。「中型 1 台」「月 2万〜4万円」の範囲が 0 から数え上がる。下に小さく「国の調査の平均から計算。待機時間料がまったく払われていない場合の上限」 |
| MG5 | 8.5 | 見出し「棚 2m40cm・400kg を新宿区から大阪市中央区へ（例）」。横棒 2 本: 「2t トラックの貸切 約 109,750 円」（灰、長い）と「帰り便 43,000 円」（青）。3.5 秒に、差に黄の括弧と「約 6.7 万円安い」。注記「貸切は国の標準的運賃からの目安（税抜）。帰り便の値段は架空で、運送会社が決めます」 |
| MG6 | 4.6 | 見出し「荷待ちの記録のサーバーへの送信」。「直す前 1 件」→ 矢印 →「直したあと 0 件」。0 件のほうに黄の下線 |

数字・文言は脚本（`docs/video/脚本.md` §2、`docs/video/shots.json`）と同じにする。MG5 の 43,000 円と 109,750 円、MG2 の 37,326 と 3,127 は画面の録画と同じ値。

## 受け入れ条件

1. `uv run python tools/video/render_motion.py MG1 MG2 MG3 MG4 MG5 MG6` で 6 本の .mov ができ、長さが表のとおり（±1 コマ）、1920×1080、30fps、透明の背景（argb）。
2. 各図のコマの一覧で、出る・数え上げ・強調・消えるの順が見て分かる。下の 300px に何も描かれていない。
3. 文字がはみ出さず、枠の中に収まる。
4. 既存の試験（`uv run pytest`）を壊さない。
