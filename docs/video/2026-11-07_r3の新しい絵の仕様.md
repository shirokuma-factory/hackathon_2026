# r3 の新しい絵の仕様（2026-11-07）

作成者の指摘: 「今の構成だと 40 点」「いきなり Backfull から始めず、社会全体の課題から入る」「最初の 5 秒で魅了する」「最後まで見たいと思えるピッチに近く」「Backfull のロゴぽいものは、こういう感じのデザインで」（暗い背景に白く光る、一筆書きの筆記体の文字。前後に線が伸びる。見本は他社のロゴなので形は真似ず、雰囲気だけを使う）。

既存の道具 `tools/video/render_motion.py` と `docs/video/motion/motion.js`・`motion.css` の作りに合わせて、`docs/video/motion/` に HTML を足し、`outputs/video/motion/<名前>.mov`（透明の背景、1920×1080、30fps、qtrle）とコマの一覧を書き出す。下の 300px は字幕のために空ける（LOGO と HOOK は例外。下に字幕が重なっても読めるよう、文字は画面の中央より上に置く）。

## 受け入れ条件

1. `uv run python tools/video/render_motion.py HOOK MG7 MG8 MG0 LOGO CH2 CH3 CH4 CH5` で 9 本の .mov ができ、長さが表どおり（±1 コマ）。
2. 各コマの一覧を開いて、動きの順序、文字のはみ出しのなさ、LOGO の光り方（芯が白く、外側が青白くにじむ）を確かめる。LOGO は暗い背景つきのコマの一覧も出す。
3. 既存の MG1〜MG6 を壊さない（`motion.js` を変えるなら MG1〜MG6 を撮り直して比べる）。
