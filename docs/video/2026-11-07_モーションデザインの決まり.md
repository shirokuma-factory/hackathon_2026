# モーションデザインの決まり（2026-11-07）

作成者の指示: 「motion graphic designer が hours and hours を使って作れる quality と内容を表現の中に入れること」「TV CM 並みの洗練」。

この決まりは、動画の中のすべての動く図・章カード・つなぎ・字幕に共通する。部品ごとに見た目と動きがばらつかないようにする。

## 1. 印（モチーフ）

ロゴ案 B の「行き = 白い実線、帰り = 点線、帰りが黄色で埋まる」を、動画全体の印として繰り返す。

- 章の切り替え、数字の強調、帰り便が見つかる場面で、この線が走る。
- 線の太さは 1080p で 6px（強調 10px）。端は丸。点線は 14px の線と 16px の空き。

## 2. 色

| 名前 | 値 | 使う所 |
|---|---|---|
| 背景 | #05080c（中心に向かって #0b1016 の放射グラデーション、四隅を少し暗く） | 全面の図 |
| 文字 | #ffffff / 補足 #9fb0c1 | |
| 強調・帰りを埋める | #f0c04a | 強調だけ。面積を広く使わない |
| 行き・比べる相手 | #6cb6ff | 行きの流れ、比べる相手の棒 |
| 空・使っていない | #3a4757（点線と空の面） | |

## 3. 文字

- Noto Sans JP（C:/Windows/Fonts/NotoSansJP-VF.ttf）だけを使う。太さは 400 / 700 / 900。
- 大きさの段: 見出し 64、数字の主役 180〜240、本文 40、補足 28。数字の単位は数字の 45%。
- 句読点は使わない。出典は図の中に書かない（画面の一番下の出典の行に出す）。

## 4. 動き

- 標準の加減速: 出る `cubic-bezier(0.16, 1, 0.3, 1)`（ease-out expo 寄り）、動く `cubic-bezier(0.65, 0, 0.35, 1)`、消える `cubic-bezier(0.7, 0, 0.84, 0)`。
- 時間: 小さな要素 0.35 秒、大きな要素 0.6 秒、要素の出の間隔（スタッガー）0.06〜0.1 秒。
- 数字は数え上げる（1.0〜1.4 秒、最後はゆっくり）。数え上げの間は桁の幅を固定してがたつかせない（等幅数字 `font-variant-numeric: tabular-nums`）。
- 動きは 1 回だけ。点滅・繰り返し・回転はしない。止まったあとも、全体をごくゆっくり寄せ続け（12 秒で 1.04 倍）、画面を完全に静止させない。
- 奥行き: 背景・図・文字を別の層にし、寄せの量を変えて（背景 1.02、図 1.04、文字 1.06）わずかな視差を出す。
- 消え方: 最後の 0.3 秒で、上へ 12px 動きながら消える。

## 5. 余白と配置

- 1920×1080 の外周 96px は空ける。下の 300px は字幕のために空ける（全面の図も、主役は上 780px に置く）。
- 箱（パネル）を使うときは、角丸 16px、#121a23 を 88%、枠 1px #2a3745。箱を重ねすぎない。

## 6. 質の確かめ方

- 各部品のコマの一覧（12 コマ）と、動きの山場の 1080p の単コマ 3 枚を、作った本人が見る。
- 文字のはみ出し、桁のがたつき、要素の重なり、急な飛びがないこと。
- 本線が最後に、動画に組んだ状態でもう一度コマを見る。
