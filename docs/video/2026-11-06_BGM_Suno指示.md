# BGM を Suno で作るときの指示（2026-11-06）

Suno（suno.com）には、このリポジトリから呼べる API も MCP もありません。そのため、作成者がサインインしたブラウザで、下の指示を貼って作ります。作った曲の採用は作成者が聴いて決めます。

## 長さと構成

動画の長さは 2:55（`docs/video/脚本.md` §4）です。ナレーションの下に敷くので、歌は入れず（Instrumental にする）、音量はあとで Resolve で下げます。

| 区間 | 時間 | 曲の役割 |
|---|---|---|
| S1 冒頭 | 0:00–0:16 | 夜の高速と木工所の実写。静かに始め、題名が出るところで一段明るくする |
| S2〜S4 課題と自社の確認 | 0:16–1:09 | 画面の操作が中心。メロディを控え、一定のリズムだけにする |
| S5 つなぐ | 1:09–1:49 | 帰り便と荷主がつながる場面。少し盛り上げる |
| S6〜S7 作り方 | 1:49–2:37 | 図とテロップが多い。S2〜S4 と同じくらい控えめにする |
| S8 締め | 2:37–2:55 | 明るく終える。最後の 2 秒で音を切らずに消していく |

## Suno に貼る指示

Style（曲調）の欄:

```
cinematic corporate, warm minimal piano, soft pulsing synth bass, light brushed percussion, gentle strings swell, hopeful, modern Japanese commercial, 92 bpm, instrumental, no vocals
```

曲名: `Backfull - Return Trip`

Lyrics の欄は使わず、Instrumental をオンにします。構成をはっきり指定したいときは、Lyrics の欄に次のように区間の目印だけを書きます（歌詞は書きません）。

```
[Intro - quiet night, sparse piano]
[Build - steady pulse]
[Verse - minimal, under narration]
[Chorus - warm lift, strings]
[Bridge - minimal]
[Outro - bright, fade out]
```

## 気をつけること

- Suno の無料プランで作った曲は、商用で使えません（Suno の利用規約）。ハッカソンの提出動画が商用に当たるかどうかは確かめていません。有料プランで作るかどうかは作成者が決めます。
- 1 回の生成で 2 曲できます。2 回作って 4 曲から選ぶ想定です。
- 3 分に届かないときは、Suno の Extend で延ばします。または Resolve で区間をつなぎます。
