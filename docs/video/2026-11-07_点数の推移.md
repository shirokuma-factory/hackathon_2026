## 作業の注意（同じ失敗を繰り返さない）

- Resolve に読み込んだファイルを、同じ名前のまま作り直すと書き出しが失敗する（G1b_c、HOOK、MG7 で 3 回）。作り直すときは別の名前で書き、`MediaPoolItem.ReplaceClip` で差し替える。
- メディアプールに同じ名前のクリップ（例: subs.mov が 2 つ）があると、名前で引いたときに古いほうを置いてしまう。フォルダを指定して引く。
- 採点役は同じ版でも ±5 点ほど動く。v6 は v4 より 3 点低いが、Claude の活用は 16 から 17 に上がった。課題（24→22）と深さ（15→14）は、v4 と v6 のあいだで変えていない部分の評価の揺れ。
- 録画は Windows Terminal を最前面に固定し、画面の範囲で撮る（gdigrab の窓の題名での録画は黒になる）。ffmpeg を止めるときは Ctrl+Break を送る（強制終了すると mp4 が壊れる）。
