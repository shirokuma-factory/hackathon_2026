# デモ動画の収録手順: 説明文の自動作成（2026-11-07）

この機能は、サーバーを環境変数つきで起動したときだけ画面に出ます。収録は、作成者が最初の本物の呼び出しを許可したあとに行います。このメモの出力例は、画面の見え方を示す見本で、本物の応答ではありません。

## 起動（収録 PC で 1 回）

PowerShell で、キーはシェルに入っている環境変数を使います（値は画面に出さない・動画に映さない）。

```powershell
$env:AI_EXPLAIN_ENABLED = "1"
uv run python tools/serve_web.py        # http://127.0.0.1:8600/
```

収録前に `http://127.0.0.1:8600/api/ai/status` を開き、`"available": true` を確かめる。偽ならボタンは出ない。

## 画面と手順

1. 書面のページ: `http://127.0.0.1:8600/waiting.html?example=1`（架空の元請A物流の例が入った状態。保存した記録は消えない）
   - 地図の画面から入る場合: `http://127.0.0.1:8600/index.html` の「自社の運行」→ 荷待ちの欄（同じボタンが書面の下書きの上に出る）
2. 画面を下へ動かし、「荷主に出す相談の書面（下書き）」の見出しの下の 「Claude で説明文を作る」を押す。
3. 「次の内容を Anthropic の API に送ります」の一覧を映す（記録の行数と欄、相手の名前、送らないもの）。ここで 3 秒止める。
4. 「送る」を押す。段ごとに表示が変わるのを映す。
   - Haiku 5.5 が記録を点検中 → 完了（指摘 N 件）
   - Sonnet 5.5 が説明文を下書き中 → 完了
   - Opus 5.5 が数字と根拠を確かめ中 → 一致
5. 「作った説明文と確かめの結果」の枠が開く。「一致」の印、説明文、記録の点検の指摘、トークン数と費用の目安を映す。
6. 「説明文をコピー」を押す（「コピーしました」が出る）。そのあと、同じ画面の下にある型どおりの書面を見せ、「説明文は添える文で、書面の数字は変わらない」ことを語る。
7. 不一致の見せ方（任意）: 録画用に Opus が不一致を返す状態は本物では再現しにくいので、動画では口頭で「確かめが通らないときは下書きを出さず、型どおりの書面に戻す」と説明する。

撮り直しのとき、同じ内容は再利用され API を呼びません（画面に「同じ内容の結果を再利用しました」と出る）。新しく呼ばせたいときは、行の時刻を 1 つ変える。

## 出力の見本（見本です。本物の応答ではありません）

```
[見本] 
1. Haiku 5.5 が記録を点検 → 完了（指摘 0 件）  入力 ○○ / 出力 ○○ トークン、約 $0.0003（目安）
2. Sonnet 5.5 が説明文を下書き → 完了（○○ 字）  入力 ○○ / 出力 ○○ トークン、約 $0.003（目安）
3. Opus 5.5 が数字と根拠を確かめ → 一致        入力 ○○ / 出力 ○○ トークン、約 $0.01（目安）

[一致]
架空 元請A物流 御中。2026-10-01 から 2026-10-16 の 12 回の荷待ちについて、記録と告示の表に当てた計算の結果をお知らせします。
参考額は合計 ○○ 円（税抜）で、請求を決めるものではなく、協議の材料です。次回の契約の書面に待機時間料の扱いを入れる方向で、ご相談させてください。
```

「○○」は実際の値に置き換わります。見本の数字を動画に使わないでください。

## 注意

- 動画に API キー、環境変数の値、`.env` を映さない。
- 費用の表示は目安（Haiku 0.10/0.50、Sonnet 2/10、Opus 4/20 ドル / 100 万トークン）。
- 公開版（Cloud Run）では既定で止まっているので、公開 URL では収録しない。
