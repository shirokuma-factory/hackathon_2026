## タイトル

Backfull ― 帰りの荷台を、荷主の荷で埋める（デモ 3 分）

## 説明欄

中小の運送会社と荷主のための道具「Backfull」のデモです。

できること
・帰りが空く場所を、国の統計と国道の大型車の数を重ねた地図で見る
・空いた荷台と荷物をつなぐ（帰り便を探す）
・荷待ちを記録して、荷主に出す相談の書面を作る（説明文は Claude の Haiku が点検と下書きをし、数字は機械で照合。動画の場面は Sonnet の下書きと Opus の確かめも動かした 11/8 の回）
・荷物の送り方を比べる（目安の額と見積の依頼文）

作り方
1 人で 1 週間、Claude Code と作りました。実装と試験は役割を分けたサブエージェント、動画は Claude から Blender・ComfyUI・DaVinci Resolve・ElevenLabs・Suno を動かして作りました。

登場する運送会社・工房・取引先・金額の一部は架空の例です。貸切の額は国の標準的運賃（令和 6 年 告示）からの目安（税抜・高速代別）です。
