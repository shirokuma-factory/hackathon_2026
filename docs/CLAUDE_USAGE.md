作成者 1 人が、5 日間（2026-11-03〜11-07）、Claude Code を開発の中心にして、アプリ・調査・3D・デモ動画を作った記録です。数字はすべてセッションの記録から数えた値で、確かめ方を各表に書きました。

| 1 人では難しいこと | Claude Code でどうしたか | 記録 |

| 物流の実体験が無いまま、法令と統計で課題を確かめる | researcher（Opus）が一次資料を開いて照合し、ページと表の位置まで記録した | `docs/plan/2026-11-03_課題の出典.md`、`2026-11-04_自社データの形と記録義務の調査.md` |

## 目的ごとのモデルと機能の使い分け

| 目的 | 選んだもの | 回数 | 選んだ理由 |
|---|---|---:|---|
| 仕様・判断・最終の確認 | 本線（Opus 5.5） | — | 作成者の意図と仕様の食い違いを見つける所なので、いちばん強いモデル |
| 実装 | `coder`（Sonnet） | 164 | 仕様が決まった実装は Sonnet で足り、上限を節約できる |
| 一次資料の調査 | `researcher`（Opus） | 19 | 法令・告示・統計の読み違いは高くつく |
| 反証・最終確認・採点 | `reviewer`（Opus）、一般のエージェント（Opus） | 26＋14 | 見落としが高くつく所と、甘い点を避けたい所 |
| 記録の洗い出しなどの読むだけの作業 | 一般のエージェント（Sonnet） | 3 | 判断が要らない |
| 機械で判定できること | Python（`tools/validate.py`、`check_ready.py`、`scan_history.py`、試験） | — | モデルに渡さない |
| アプリの説明文 | Haiku 5.5 → Sonnet 5.5 → Opus 5.5 | — | 安い順に点検し、高いモデルは数字の確かめだけ（SPEC §53） |

## 荷待ち協議の書面の説明文の自動作成（2026-11-07、SPEC §53）

アプリの機能として Claude API を使う（開発の道具ではない）。公式の `anthropic` Python SDK（`uv add anthropic`）で、3 段に分ける。

| 段 | モデル | 役目 | effort | max_tokens |
|---|---|---|---|---|
| 記録の点検 | `claude-haiku-5-5` | 時刻の抜け・順序の食い違い・重複を JSON で返す | low | 2,000 |
| 説明文の下書き | `claude-sonnet-5-5` | 渡した事実だけから 600 字以内の説明文 | medium | 4,000 |
| 数字の確かめ | `claude-opus-5-5` | 下書きの数字・主張を事実と突き合わせ、JSON で一致か不一致かを返す | medium | 6,000 |

- max_tokens は思考の分を含む。自動の再試行はしない（二重課金を避ける）。1 回の最悪の費用は約 $0.33（仮定: 事実 30 KB）。
- 安い順に点検し、いちばん高いモデルは数字の確かめだけに使う。確かめが通らなければ下書きは出さず、型どおりの書面に戻す。数字の機械照合は Python でも行う。
- 守り: `AI_EXPLAIN_ENABLED=1` が要る（既定は止）。公開版は `AI_EXPLAIN_PUBLIC=1` も要る。1 日 `AI_DAILY_LIMIT`（既定 100）、来訪者ごとに 1 時間 10 回、事実は 30 KB まで、同じ内容は再利用。キーは環境変数 `ANTHROPIC_API_KEY` だけで、`.env` は読まない。
- 試験は SDK を差し替える（`tests/test_v53_ai_explain.py`）。本物の呼び出しは作成者の許可を得てから最初の 1 回を行う。
- 自社の運行記録の列の整理（SPEC §53.1）: `claude-haiku-5-5` を 1 回、effort low、max_tokens 2,000、JSON スキーマ。送るのは列の見出しと値の形の要約だけで、セルの値は送らない。上限・有効化の条件は上と同じ。試験は `tests/test_v53_own_columns.py`（SDK を差し替え）。
- 帰り便の案内文の整え（SPEC §53.2）: `claude-haiku-5-5` を 1 回、effort low、max_tokens 1,500、構造化出力なし。送るのは確認を取った案内文の本文だけ。戻りは【】・曜日・「…周辺」・数字・長さを Python で照合し、落ちた案は「確認が必要な案」として出す。1 回 約 $0.001 以下（仮定）。試験は `tests/test_v53_offer_polish.py`（SDK を差し替え）。
