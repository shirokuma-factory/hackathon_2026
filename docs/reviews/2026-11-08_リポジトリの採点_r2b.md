## 利用者として進めた手順と、詰まった所

1. README の 15 行の URL を開いた。最初の 1 回は十数秒かかると書いてあり、その通りだった。開くと架空の例が入っていた。
2. Excel の 5 行（見出しつき）をコピーして「貼り付けた内容を表に入れる」を押した。「5 行を足しました」と出た。
3. 「荷主の都合で待ったかの列が無いので、全部『はい』で計算しました」「荷役をした人が分からないので、荷役の時間は待機にも積込料にも入れていません（5 行）」の 2 つの注意が出た。車種は空欄なので「中型」で計算された（メールの本文にも書かれる）。
4. 「契約の相手が空の 5 行は、仮の相手で計算しています」の欄に元請の名前を入れ、「全部の行に入れる」を押した。宛名・件名・本文がその名前で揃った。
5. 「本文をコピー」の中身（`draftText`）を読んだ。参考額 20,410 円、計算のしかた、出典、契約に入れたい項目まで入っている。ただし P1-4〜6 の 3 か所は、元請に出す前に自分で消す必要があった。

詰まった所は、相手の名前を入れる欄の名前が「荷主」だったこと（元請でよいのか迷った）と、ドライバーが手積みしている会社なのに荷役の額が 0 円になったことの 2 つです。後者は注意の文を読めば理由は分かりますが、直し方（荷役をした人を「運転者」にする）は、表の行ごとに選び直すしかありません。まとめて替えるボタンは車種と荷役の方法の空欄だけです（`tools/waiting_page_template.html` 694〜705 行の `bulkFillDefault`）。
