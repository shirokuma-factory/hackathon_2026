# 画面の出来と印象の採点 r2b（2026-11-07、第 8 部の基準）

採点者: 独立の採点役（Claude）。過去の採点の文書は読んでいません。中小の運送会社の配車担当と、中小荷主の出荷担当として、初めて開く想定で操作しました。

結論: 合計 **63 点 / 100 点**（観点の合計 74 点、減点 −11 点）。合格の線（95 点）に届いていません。いちばん効く直しは、全国の物流傾向から「この区間の帰り便の空きを探す」で進んだ先が、選んだ区間を引き継がずに空の一覧で止まる点です。

## 確かめたこと

手元の版（`tools/serve_web.py`）と公開版（`--public`）を、空いているポートで自分の Python から起動し、終わりに止めました。ヘッドレス Edge は同時に 1 つだけ（`tests/conftest.py` の `edge_page`）で動かしました。画面写真は `（作業用の一時フォルダ）/grade8_r2b\` にあり、下の判断はその写真を開いて見た結果です。数値の元は同じフォルダの `result.json` です。

数え方: 最初に目に入る範囲の、見えているテキストノードの文字数（地図の canvas と `.maplibregl-ctrl-attrib` を除く、`tests/viewport_text.py` と同じ）。押せる所は、画面内に見えている button・リンク・入力・summary の数です。主なボタンは画面内の `.btn-primary` の数です。
