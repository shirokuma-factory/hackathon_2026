## 前提として見えたこと

- 8655 のサーバーは `data/tariffs/private/`（git に入れない実在の会社の表）を読んでいました。証拠: 東京都新宿区→大阪市北区のカゴ台車 1 本が 23,100 円で、`private/yamato_jitbox.json` の値と一致します。架空の見本 `sample_jitbox.json` なら 20,000 円です（`SHIPCOMPARE_DATA_DIR` を private なしの写しに向けて `estimate_all` を流し、20,000 円・宅配 909 円・路線便 1,800 円を確認）。公開の版とこの手元のサーバーでは宅配・路線便・カゴ台車の額が違います。
- compare_lite は宅配・路線便の表を持たず（契約単価を入れる形）、宅配だけ架空の表の例（`PUBLIC_TAKUHAI`）を出します。
- 試した荷と区間: 60 サイズ 1 個、120 サイズ 3 個 40kg、50kg の箱、パレット 1 枚 1100×1100×1500mm 450kg、パレット 2 枚 900kg、長さ 3.5m の荷、2,100kg、9t、個数 0・負の数・空欄、mm と cm の見出し、入数・総重量の列を含む貼り付け、東京→大阪・札幌・那覇・鹿屋（鹿児島県）、同じ区（新宿区→新宿区）、近い区（新宿区→千代田区 6.3km）、大阪→東京、鹿児島→東京（compare_lite）。
- 手計算の照合（標準的運賃、関東、`data/tariffs/mlit_standard_fare_kanto.json`）: 2t・500km は 52,300 + ceil((500−200)/20)=15 段 × 3,830 = 109,750 円。画面（両方）と一致しました。4t・492km の 126,060 円、10t・500km の 167,860 円、2t・1,945km の 52,300 + 15×3,830 + ceil(1,445/50)=29×9,580 = 387,570 円も一致しました。表の計算そのものに誤りは見つかりませんでした。
- 文で書いて AI に表にしてもらう欄: `/api/ai/status` が `available:false` のとき、地図の画面の `#cargo-ai` は空（innerHTML の長さ 0）で、`/api/ai/*` への POST は 0 件でした。使える状態では試していません（実際の API は使わない約束のため）。
- 画面のエラー（console.error と window.onerror）は、どちらの画面でも 0 件でした。1920 と 390 の幅で横にはみ出す要素はありませんでした（compare_lite は scrollWidth 390）。
