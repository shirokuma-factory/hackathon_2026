# 道具の採点 r3a（第 6 部、2026-11-06）

採点基準は `docs/plan/2026-11-04_解決の筋書き_採点基準.md` の第 6 部です。重点は、境界の入力での計算と予約の正しさ、同じ値が画面ごとに違わないか、データがブラウザの外に出ないか、の 3 つです。対象はコミット da68a18 の作業ツリーです（動画のファイルは対象外）。前の回の採点ファイルは読んでいません。

## 結論

合計 **84 点**（観点の合計 90 点、減点 −6）。合格の線 95 点には届きません。

点を下げた主な理由は 2 件の計算の誤りです。

1. 同じデジタコの CSV を 2 回落とすと、区間が二重に数えられます（107 → 125 区間、実車率 76.9% → 77.1%）。注意は出ません。
2. 帰り便の値段の式で、荷の床が荷台の床より大きいと、1 件の参考額が 181,056 円になります。荷台 1 台の距離制運賃 120,050 円より高い額です。重さは 100% を超えると「載りません」と断りますが、床は断りません。

予約の盤（ちょうど上限、出発の時刻ちょうど、期限切れ、辞退での戻し、時差つきの締切）と荷待ちの計算（Python と JS の一致）は、試した境界の入力ですべて正しく動きました。自社のファイルの取り込みの前後で `/api/` への通信は 0 件、荷待ちのページと比べるページは外への通信が 0 件でした。
