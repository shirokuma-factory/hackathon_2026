# 不具合探し: 自社の運行（運行記録を見る・own_lite.html・帰り便の案内）2026-11-08

中小運送会社の配車担当として、自社の CSV を 18 本作って読み込み、数字と案内文を確かめました。サーバーは http://127.0.0.1:8655/（起動済みのものをそのまま使用）、ヘッドレス Edge（tests/conftest.py の edge_page）で、ファイルの欄に DOM.setFileInputFiles で入れています。AI の確認は `/api/ai/*` をページ内で差し替えて行い、実際の API キーは使っていません。

作った CSV（スクラッチの `csv/`）: 縦の配車表（UTF-8 / Shift_JIS + CRLF）、横の配車表（車番 + 10/1〜10/31）、デジタコの明細（開始日時,終了日時,区分,地点,距離,実空）、日ごとの集計（Shift_JIS）、車番の列なし + 走行km、日付の書き方の混在（2026/10/5・2026-10-06・10/7・2026年10月8日・R8.10.9・2026/10/12(月)）、夜をまたぐ便、月またぎ（9/28〜10/4）、同じ内容 2 ファイル（同時・別々）、620 行、辞書にない地名、見出しなし（2 種）、Excel の BOM + 引用符 + 末尾の空列、辞書にない見出し、アプリの「見本の CSV を保存」と同じ内容。
