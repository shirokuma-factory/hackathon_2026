## 見つけて直したこと

- 1 回目の説明文に「正直に申しますと、待ちの長さが続いているのが気がかりです」が出た。下書きの指示が、まだ手紙（拝啓〜敬具）に添える添え書きを前提にしていたので、メールに添える段落に直し、気持ちを打ち明ける言い回しを使わない決まりを足した。2 回目はこの言い回しが出なかった。

## 残っていること

- 説明文の期間が「2026-10-01から2026-10-16まで」と ISO の形で出る。事実の期間が ISO で渡っているため。日本語の日付（10月1日〜10月16日）で渡すには、数字の機械照合の扱いも合わせて変える必要があるので、今回は直していない。
- 構造化出力（数値欄の null を許す書き方）は、荷物の文 → 表で本物の API でも通った。
