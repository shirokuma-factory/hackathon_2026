## よかったところ

- 起動が速い（4.4 秒）。全操作で画面のエラーが 0 件でした。
- 区間の順位の行き・帰り・偏りの比・距離は、丸めの 1 t を除いて表とカードと案内の一覧で一致していました（兵庫県→東京都 37,326 / 3,127 / 34,199 / 429 km）。
- 想定の計算は式どおりでした（62.15 × (1 + 0.05 × 0.3447) = 63.22、X = 20% で 66.44）。前提を開くと式と 5 つの前提が読めます。
- 法人番号の桁が足りないときは「13 桁の数字で入れてください」と出て、空欄なら個人事業主として保存できます。
- T7 の流れ（仮予約 → 運送会社の画面で承諾 → 書面 → 確定）は、締切の残り時間、残りの重さ（2,000 → 1,880 kg）、床の空き（6 → 4.2 m²）が画面の間で一致していました。
- 各画面から「最初の画面に戻る」とブラウザーの戻るが効き、「いまの大型車」からも「地図の画面に戻る」で戻れます。
