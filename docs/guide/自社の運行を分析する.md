# 自社の運行を分析する

配車担当・運行管理者向けの手引きです。自社の配車表とデジタコの CSV を、地図の画面の「自社の運行」に落とすと、実車率・積載率・積載効率、空車で走った距離、帰りが空く曜日、30 分以上の停車を出します。計算はすべて自分のブラウザの中で行い、ファイルは外に送りません。CSV の中身はページを閉じると消えます。数字の要約・地名の対応・確認の決定・列の役割は、このブラウザに残ります（「月ごとの保存」の欄で消せます）。

## 先に知っておくこと

| 項目 | 内容 |
|---|---|
| 読めるもの | 配車表（日付が横に並ぶ形、1 行 = 1 便の縦の形）の CSV と、デジタコの CSV（1 回ごとの走行・停車の明細、日ごとの集計）。UTF-8 と Shift_JIS の両方。Excel から出した形（上に題名の行がある、見出しが日の数字だけ、曜日の行、号車や乗務員や合計の列）も読みます |
| 読まないもの | 紙の日報、チャート紙、写真、Excel のファイルそのもの（.xlsx）。Excel は「CSV UTF-8」で保存し直してください |
| 出てくる数字 | 目安です。法令で残す元の記録は、別に保管してください |
| 費用 | 単価は自分で入れます。入れるまで費用は出しません。削減額の約束ではありません |
| 試してみる | `examples/own/` の 3 つのファイル（架空の会社）を落とすと、サンプルとほぼ同じ画面になります。数字は完全には一致しません（下の「例のファイルとサンプルの数字の違い」）。実務の形の例（すべて架空）は「例のファイル」の表にあります |
| 確かめた範囲 | 実在の会社の配車表・デジタコでは確かめていません。Excel の書き出しの実務の形を想定して作った架空のファイルで、読めることを試験しています。読めない列は、画面で「これは日付」「これは使わない」と選べます |

## 使い方

1. 配信サーバーを起動します（`uv run python tools/serve_web.py`）。表示された住所を開き、上の切り替えで「自社の運行」を選びます。
2. 左の「自社のファイルを落とす」の欄に、CSV を落とします。クリックして選ぶこともできます。配車表とデジタコは、まとめて落としても、1 つずつ落としても構いません。同じ名前のファイルを落とし直すと、新しいほうに置き換わります。
3. 左の「いま見ているデータ」に「自社のファイル: ○件」と出ます。区間も停車も取り出せなかったファイルは数に入れず、「（読めなかった ○件）」と分けて出します。「サンプルに戻す」で、架空の会社のサンプルに戻ります。
4. 左の 3 つのタブで、取り込みの結果、確認が必要な項目、気づきを見ます。右に数字と、区間 × 向き × 曜日の表が出ます。
5. 右の「費用への換算」に単価を入れると、費用が式つきで出ます。「区間の判定を CSV でコピー」「数字と気づきを文でコピー」で、結果を貼り付けられます。

## ファイルの用意

### 配車表

2 つの形を読みます。列の名前（見出し）は、次の表の名前なら読めます。見出しの行は先頭の 10 行の中から探します（上に題名の行や空行があってもかまいません）。見出しの行は、車番の列があり、日付の列が 3 つ以上並んでいる行（縦の形は、日付・車番・発地か着地の列がある行）です。

#### 横の形（1 行が 1 台の車、列が日付）

| 列 | 書き方 |
|---|---|
| 車番の列 | 見出しに「車番」「車両No.」「車両番号」「ナンバー」「車両」のどれか。他に車番の列が無いときだけ、「号車」「No」も車番として読みます（通し番号のことがあるため）。「神戸 100 か 1234」「4t-1234」「1234」のどれでも、末尾の 4 桁を車番として読みます |
| 車種の列 | 見出しに「車種」「車格」「トン数」のどれか。「大型」「4t」「2t」「4トン」など。8t 以上は大型として数えます |
| 日付の列 | 見出しは「10/1(木)」「10月1日」「2026/10/1」「2026年10月1日」のどれか。年が無い見出しの年は、見出しの曜日（木）に合う年にします。今日の日付では決めません。12/11〜1/10 のように年をまたぐ表は、1 月以降を翌年にします |
| 日の数字だけの見出し | 見出しが「1」〜「31」（または「1日」〜「31日」）のときは、見出しの上の題名の行（「2026年10月 配車表」「10月分」）の月の日として読みます。見出しの下の行が曜日（月〜日）なら、年を決める手掛かりにします。題名にも月が無いときは、デジタコの日付の月を使います。どちらも無いときは「月が分かりません」と出し、読みません（月を指定して読み直せます） |
| 読まない列 | 「乗務員」「運転者」「合計」「備考」「稼働日数」「荷主」など。読まなかった列は、取り込みの結果のファイルの欄に書きます |
| 備考・荷主・摘要の列の空車の印 | 縦の形（1 行 = 1 便）で、「備考」「荷主」「摘要」「メモ」「得意先」の列に「空車回送」「空」「回送」「帰荷なし」と書いてあれば、その便を空車として読みます（「空港運輸」のように、前後が文字の「空」は印にしません）。列の役割で「実空の印がある列」を選んでも同じです。列の役割で「読まない」を選んだ列は見ません |
| 号車の番号 | 4 桁の車番がどの行にも無く、「1号車」「１１号車」「3号」「7」のような 1〜3 桁の番号が並ぶ配車表は、「N号車」をそのファイルの中の車の名前にします。デジタコの車番とは結びつきません |
| 日付の空欄・「1日」・和暦 | 縦の形で日付が空欄の行は、上の行の日付で読みます（車番が空欄の行も上の車番）。「1日」「1」は題名の行の年月（「令和8年10月」「2026年10月」）と合わせて読みます。「R8.10.1」「令和8年10月1日」「2026.10.01」も読みます。横の形の見出し「1日(木)」「1日（木）」も日付です |
| 先頭の「帰り」「戻り」 | 「帰り 江東→加古川 荷なし」の「帰り」は区間の名前に入れず、「荷なし」「空」があれば空車にします |
| 読み飛ばす語 | 「休」「休み」「整備」「車検」「待機」「点検」「定期点検」「修理」だけのセルは、区間に数えません |
| 経由地 | 「江東→加古川→大阪」は、「江東→加古川」と「加古川→大阪」の 2 区間に分けます（積んでいる重さはどちらにも付けます） |
| 同じ地名の施設 | 地図の市区町村に当たらない地名で、倉庫・センターなどを外すと同じになるもの（「辰巳倉庫」「辰巳DC3」→「辰巳」）は 1 つの地点にまとめます。取り込みの結果の欄の「まとめない」で止められます |
| 合計の行 | 車番の欄が「合計」「計」の行は読みません |
| 荷主などの備考 | 車番の欄を空にした次の行に書くと、上の車の備考になります。空行を入れると、その先は上の車番を引き継ぎません |

日付が縦に並び、車が横に並ぶ表（左端の列が日付で、見出しの行に 1234・5678 のような車番が並ぶ形）も読みます。日付が横の形に置き換えて読み、画面の「元の行」は元のファイルの行と列を示します。見出しに日付が並ぶ表と、1 行 = 1 便の縦の形は置き換えません。

セルの書き方は「積地 → 降ろし地 着5:30 4.6t（空）」です。

| 部分 | 内容 |
|---|---|
| 積地 → 降ろし地 | 矢印は「→」「⇒」「=>」「->」「>」「～」「〜」のどれでも。地名は市区町村の名前で始めてください（後の「地名」を参照）。「東京 江東区」「東京都江東区」のように都道府県が付いていてもかまいません（積地にも降ろし地にも付けられます）。都道府県のあとに市区町村が続くときは、都道府県を読み飛ばして市区町村を地点にします。「東京」だけのときは、地図に置けない地点として確認のタブに出ます（距離が分からない区間は、実車率に入りません） |
| 降ろし地が無い | 「加古川 → 4.6t」「江東 → 着5:30」のように矢印の後ろが重さか時刻のときは、降ろし地は空欄で、後ろの語を重さ・時刻として読みます。重さは地名にしません（地名の別名に登録できません）。積地と降ろし地がそろわない区間は、空の印が無ければ「不明」にして、確認のタブにカードを出します |
| 着5:30、5:30着 | 到着の目安。「530」「5:30」「05:30」「5時30分」「5時」「5時半」を読みます。「着」の前でも後ろでもかまいません。「5:30着 9.2t」の 9.2t を時刻としては読みません。「8時半ごろ着」「頃」のような概算や、読めない時刻は、時刻だけ使わず、区間は読みます（取り込みの結果に件数が出ます） |
| 4.6t、4600kg、5トン | 積んだ重さ。t・kg（`4,600kg` も）・トンで読みます。`1e3kg`、`1e3t` のような指数の書き方は、理由つきで読めない行にします。大型の積載率の計算に使います。数のすぐ後ろに「車」「ウイング」「箱」「平」「ユニック」などが続くとき（「4t車」「5トンウイング」）は、車の大きさで、重さではありません。「加古川 → 江東 4t車 2.5t」は 2.5t です。`-1t`、`+5t` のように符号が付いた重さは読めない行にします。単位が無い数（`4600`）と `6.5ton` は重さと見なしません |
| 重さが 2 つ以上 | 1 つのセルに別々の重さが 2 つ以上（`3t 4t`）あるときは、どれか分からないので重さなしで数え、確認のタブにカードを出します。同じ重さの繰り返しは 1 つとして読みます |
| 0t の実車 | 重さが 0t の実車の区間は、積載率に入れず、確認のタブにカードを出します |
| 空車の印 | 「空」「帰り空」「帰り空車」「戻り空」「戻り空車」「回送」「空回送」「空荷」「荷なし」「荷無し」「カラ」「空車」「（空）」のどれか（縦の形の「区分」の列も同じ表で読みます）。区間の前に付けても読みます（「回送 江東 → 加古川」「（回送）江東→加古川」「回送：江東→加古川」は、後ろに付けた「江東 → 加古川 回送」と同じ空車です）。「回送」と「空コン」は、前後に何が付いていても空車の印です（半角カナの「空ｺﾝ回送」も同じ）。「帰り」「戻り」だけの語は、同じ区間に重さが書かれていないときだけ空車の印にします（重さがあれば実車です）。積地と降ろし地が両方あれば実車、空車の印があれば空車、片方が空欄なら不明になります。「空港前」のように別の言葉の中の「空」は印にしません。「空」だけのセルは、積地・降ろし地の無い空車になります。空車の印にならなかった語（「冷凍」「納品」など）が実車の区間のセルに付いていたときは、結果の「実車として数えた区間のセルに付いていた語」に一覧を出します。空車の意味の語があれば、印に書き換えて落とし直してください |
| 実車の印 | 「実車」「（実車）」「積載」。車庫へ戻る区間（降ろし地が自社の車庫）で、空車の印も重さも無いものは、実車か空車か分からないので「不明」にして確認のタブに出します。重さの代わりに「実車」と書くと、実車として数えます |
| 2回転、往復 | 「姫路市→神戸市中央区 2回転」は、その区間を 2 回の実車として数えます |
| 加古川市内 ルート配送 | 矢印の無い「市内」「ルート」「巡回」「地場」「集配」のセルは、その地名の中の地場の配送として、実車に数えます（距離は出さないので、実車率の計算には入りません） |
| 傭車 | 車番の欄（か車種の欄）に「傭車」「外注」「協力会社」と書いた行は、自社の車ではないので読まず、傭車の行・日数・区間として別に数えます（取り込みの結果とお知らせに出ます） |
| 休・整備・休み・車検・待機 | 区間として数えません |
| 1 つのセルの複数の区間 | 「／」「/」、セルの中の改行（Alt+Enter）、「AM … PM …」（午前・午後も）で区切ると、区間ごとに読みます。「AM 姫路→明石 3t / PM 明石→姫路 空」は 2 区間です |

#### 縦の形（1 行が 1 便）

見出しに「日付」「車番」「発地（積地）」「着地（降ろし地）」の列があれば読みます。ほかに「重量（t）」「重さ」「時刻（着時刻）」「区分（実車・空車）」の列があれば使います。重さが数だけのときは、見出しの単位（`重量(t)`、`重量kg`）で読み、見出しに単位が無ければ 100 以上を kg、100 未満を t とします。

#### 車番の書き方が似ているとき

「品川100あ1234」と「練馬100い1234」のように、地名・分類番号・かなが違う車番は、末尾の 4 桁が同じでも別の車として数え、確認のタブにカードを出します。片方が「1234」だけのときは、同じ車として数え、確認のタブに出します。デジタコのファイル名の 4 桁が複数の車に当たるときは、4 桁だけの車、無ければ配車表で先に出る車に当て、確認のタブに出します。

「春日部130え4521（4t・高橋）」と「4521（大型・中村）」のように、末尾の 4 桁が同じで車格か運転者が違うときも、別の車として数え、確認のタブにカードを出します。

#### 配車表を複数落としたとき

月違い・営業所違いの配車表をまとめて落とすと、全部を読みます。車番と日付が重ならない配車表は合わせて使います。重なるときは、先に読んだ配車表だけを使い、重なった配車表と件数を取り込みの結果に出します（内容が同じなら「同じ内容なので読んでいません」）。使う配車表は画面で選べます。

- 「合わせて読みました」に数えるのは、区間を 1 件でも取り出せた配車表だけです。見出しだけの配車表や、重なりで全部捨てた配車表は数えません。結果の `files_used` が、使ったファイルの一覧です。
- 先に読んだ順が、重なるマスで優先される順です。同じファイルを落とし直しても順位が変わらないように、画面は前の順位を `file_order` で渡せます。順位を保ったときと、使う配車表（`prev_haisha_used` と比べて）が変わったときは、お知らせに出ます。
- 1 つずつ落としても、2 か月以上を一緒に落としても、月ごとに数えます。見出し・保存・前の月との比べは、月ごとの値どうしでします（地図の画面にも 1 枚のページにも同じ）。同じ月の別の版のファイルを落とし直すと、その月の保存は最新の 1 件に置き換わります。結果の `months_detail` に、月ごとの件数・率・曜日の表・組ごとの集計・気づきがあり、`multi_month` と `month_label`（例: 「2026 年 10 月〜11 月（2 か月分）」）で見出しを付けます。月の比べは、この月ごとの値どうしでします。

読めないセルは、理由つきで「取り込みの結果」に並びます。読めたものだけで計算します。

#### 列の役割を選ぶ

見出しが上の表に無い列（役割が決まらない列）は、画面で役割（日付・車番・発地・着地・重さ・時刻・車種・使わない）を選べます。選んだ役割は、同じ形のファイル（見出しの並びが同じ）のために覚えておけます（ファイルの形の目印は、解析の結果の `shape_signatures` で返します）。ファイルが読めなくなる列は、必ず選んでもらう列として先に出します。読めたファイルの中の、役割が決まらなかった列は、「使わない」を初期値にして出します。

#### 年の決め方

- 見出しに曜日がある（「10/1(木)」）とき、その曜日に合う年を 2020〜2036 年の中から探します。1 年だけ合えば、その年にします。
- 合う年が複数あるとき（たとえば 10/1 が木曜なのは 2020 年と 2026 年、金曜なのは 2021 年・2027 年・2032 年）は、先にファイルの名前・題名の行（「2026年10月」「令和8年」）・デジタコの日付・保存した前の月にある年を使います。手掛かりが無いときは、候補のうち 2026 年（デモの年）にいちばん近い年にして、画面に「2026 年としました（変えられます）」のように出します（2027 年 10/1(金) が 2021 年にはなりません）。今日の日付（時計）は使いません。年を選び直すと、その年で計算し直します。
- 曜日が無い、または曜日がどの年にも合わないときも、2026 年として計算し、年を選び直せるようにします。
- デジタコの日付があるときは、その年に収まる年に絞ります。
- 配車表もデジタコも読めず、区間が 1 件も取れなかったときは、取り込みの失敗として扱います。前の表示（サンプルか前に読んだ結果）はそのままです。

### デジタコの CSV

1 行が 1 回の走行か、1 回の停車の形です。ファイル名に車番 4 桁を入れてください（`digitaco_1234.csv`）。車番が読めないファイルは読みません（日ごとの集計は、車番の列があればそれを使います）。見出しの行は、配車表と同じく先頭の 10 行から探します。

| 役割 | 見出しの名前（大文字小文字は区別しません） | 値 |
|---|---|---|
| 区分 | KBN、区分、イベント、種別 | 1 か「走行」が走行、2 か「停車」が停車 |
| 開始の日時 | ST_TIME、開始日時、開始時刻、開始、開始時間、出庫 | 2026-10-06 20:10、2026/10/6 20:10、全角の数字（`２０２６/１０/６ ２０:１０`）。秒は捨てます。時差つき（`+09:00`）と区切りの無い形（`20261006T2010`）は読みません |
| 終了の日時 | ED_TIME、終了日時、終了時刻、終了、終了時間、帰庫 | 同じ形 |
| 走行距離（km） | ODO_KM、走行距離、走行距離(KM)、区間距離、距離 | 551.8 のような数字 |
| 実車・空車 | JK_FLG、実空区分、実車空車、実空、状態 | 1・実・実車が実車、0・空・空車が空車 |
| 停車の地点名 | POS_NAME、地点名、停車地、停車場所、場所、地点 | 地名（市区町村の名前で始めてください） |
| 運転者 | DRV_CD、乗務員コード、運転者コード、運転者、乗務員 | 運転者のコード |
| 運行日 | 運行日、日付、年月日 | 開始・終了が「20:10」のように時刻だけのとき、この日付に足して日時にします。終了が開始より前なら翌日、同じ運行日の続きの行は前の行の終了以降の日にします |

見出しの全角・半角の違いと大文字小文字は区別しません。Python（`src/shipcompare/own.py`）とブラウザ（`web/own_calc.js`）は同じ表で読み、`tests/test_v40_own_fixes.py` が同じ入力を両方に通して照合しています。見出しがこの表に無い列（例の `X9`）は、読まずに進めます。開始と終了の日時の列が見つからないファイルは、「配車表にもデジタコにも見えません」と出して読みません。そのとき、見出しとして見た行（行番号と、その行のセル）と、見出しをどう直せば読めるかの例を、読めなかったファイルの欄に出します。画面で各列の役割（開始の日時・終了の日時・走行距離・実車か空車か・停車した場所など）を選ぶと、そのとおりに読みます。

#### 日ごとの集計の形

見出しに「日付」「実車距離」「空車距離」（あれば「車番」「出庫」「帰庫」）の列がある形です。「実車距離(km)」「空車距離（km）」のように見出しの後ろに単位がつく書き方、「車輌番号」「車両番号」「乗務員名」「出庫日時」「帰庫日時」も読みます。車番の列があれば（辞書で分かった列も、画面で「車番」と選んだ列も）、ファイル名に車番 4 桁は要りません。1 行（1 台の 1 日）から、実車距離が 0 より大きければ実車の走行、空車距離が 0 より大きければ空車の走行を作ります。地点は分からないので、実車率には使えますが、行きと帰りの表や気づきの規則 1 には使えません。配車表と一緒に落としたときは、同じ走行を二重に数えないように、日ごとの集計は実車率の計算に入れず、その旨を画面に出します。

#### 同じ記録を 2 回落としたとき

車番・開始・終了・距離が同じ走行、車番・開始・終了・地点名が同じ停車は、1 回だけ数えます。取り込みの結果に「同じ走行・停車の行 ○ 件は、1 回だけ数えました」と出します（名前の順で後ろのファイルの行を捨てます）。

次の行は読めない行として理由を出し、計算に入れません。

| 行 | 理由 |
|---|---|
| 終了の日時が開始の日時と同じか、それより前 | 終了が開始より前（または同じ）です |
| 日時が読めない（`20261006T2010` のような区切りの無い形を含む） | 時刻が読めません |
| 区分が 1・2 のどちらでもない | 区分が読めません |

走行距離が数でない行（`abc`、`1e3`、負の数）は、「距離が読めません」と出し、距離を空にして続けます。全角の数字、カンマ（`1,234.5`）、末尾の `km` は読みます。

### 文字コードとファイルの大きさ

UTF-8 として読めなければ、自動で Shift_JIS として読みます。「取り込みの結果」のファイルの欄に、どちらで読んだかが出ます。1 ファイル 20MB までです。

### 地名

地図に置く場所は、地名の先頭が市区町村の名前に当たるかで決めます。「江東区辰巳」は江東区、「加古川営業所」「加古川」は加古川市に置きます。同じ名前の市区町村が複数の県にあるときは、置きません。

当たらなかった地名（例の「辰巳」）は、左の「取り込みの結果」の「地図に置けない地点」に並びます。線には引きませんが、実車か空車かの判定には使っています。欄に市区町村名（例: 江東区）を入れて「地図に置く」を押すと、その名前を含む地名をすべてその市区町村として、計算し直します。

## 確認のタブ

確かさが 0.9 未満の列の対応づけと、配車表とデジタコで時刻・距離がずれた区間が、カードで並びます。「確定」「修正」「読まない」を押すと、その決定を計算に渡して、数字を計算し直します。「取り消す」で元に戻ります。

| カード | 修正 | 読まない |
|---|---|---|
| デジタコの列の対応づけ | 入れた役割（例: 走行距離、開始の日時）でその列を読む | その列を読まずに計算する |
| 距離のずれ | 入れた距離（km）にする | デジタコの距離を使わず、推定距離を使う |
| 時刻のずれ | 入れた時刻にする（実車率などは変わりません） | デジタコの到着時刻を使わず、配車表の着の時刻を使う（実車率などは変わりません） |
| 積んだ重さ（最大積載量を超える、0t の実車、1 つのセルに重さが複数） | 入れた重さ（`4.6t`、`4600kg`）にする。まだ超えていれば率に入れない | 重さを読まない扱いにする（率に入れない） |
| 車番の末尾 4 桁が重なる | 計算は変わりません（印を付けるだけです） | 同じ |
| 車庫へ戻る区間で、空車の印も重さも無い | 「空」と入れると空車、「実車」と入れると実車として、その区間すべてを数え直す | 不明のまま（実車率に入れない） |
| 配車表の列、地点の別名 | 計算は変わりません（印を付けるだけです） | 同じ |

「確定」は印を付けるだけで、値は変えません。各カードの「反映」の欄に、押すと何が変わるかが出ます。サンプル（架空の会社）を見ているときは、数字が固定なので、押した結果は計算に反映されません。

## 数字の読み方

### 区間の判定（実車・空車・不明）

次の順で決めます。上で決まれば、下は見ません。

1. デジタコの実空区分
2. 配車表（「空」などの印は空車。積地と降ろし地が両方あれば実車。ただし車庫へ戻る区間で、空車の印も重さも実車の印も無いものは不明）
3. 決まらなければ不明

不明の区間は、実車率の計算に入れません。不明が 15% 以上のときは、気づきに出ます。

### 距離

デジタコの走行距離を使います。デジタコの無い区間は、積地と降ろし地の代表点の直線距離の 1.25 倍を、道のりの推定として使います（係数 1.25 は仮定です）。どちらを使ったかは、区間の判定の CSV の「距離の出どころ」に出ます。

### 実車率

- 式: 実車の km ÷ 走った km（実車か空車かが判定できた区間だけ）
- 判定できた区間が全体のどれだけかも、数字の下に出ます。
- 不明の区間を空車として数えた場合の率は、`kpis.loaded_rate_if_unknown_empty`（実車率）と `kpis.empty_rate_if_unknown_empty`（空車率）にあります。不明の区間のうち km が分かるものだけが入り、件数は `kpis.unknown_as_empty`（`unknown_legs`、km が無くて入らない `unknown_legs_without_km`）にあります。読めなかった行の数は `counts.unreadable_rows` です。読めなかった行は区間にならないので、どちらの率にも入りません。

### 積載率

- 式: 積んだ重さ ÷ 最大積載量。大型の実車の区間のうち、重さが分かる区間の平均です。
- 最大積載量が分からないときは、大型を 10t と仮定します。右の欄で変えられます。車ごと・車格ごとの値（`max_payload_by_plate`、`max_payload_by_class`）を渡すと、率と「最大積載量を超える」カードはその値を使います（車ごとが車格ごとより先です）。
- 積んだ重さが最大積載量を超える区間（12t や 99t と書いてあるなど）は、平均に入れません。入れると 120% や 500% になるためです。数字の下に「最大積載量を超える重さの記録 ○件は入れていません」と出し、確認のタブにカード（修正・読まない・確定）を、気づきに規則 7 を出します。t と kg の取り違えや桁の間違いを、元の配車表で確かめてください。「修正」で `4.6t` や `4600kg` を入れると、その重さで計算し直します。
- 重さが書いてある区間が少ないと、計算できた区間の割合が小さく出ます。割合が小さいときは、参考程度に見てください。

### 積載効率

- 式: 大型の積載率 × 大型の実車率

右の 3 つの数字の下の「3 つの数字の式を見る」を押す（キーボードの Enter でも開きます）と、3 つの式がそのまま出ます。

## 国の数字との比べ方

| 数字 | 国の値 | 自社の値の式 | 範囲と式の違い |
|---|---|---|---|
| 実車率 | 62.15%（営業用普通車、2025 年度、自動車輸送統計年報） | 実車の km ÷ 走った km | 自社の車すべてが範囲です。国は営業用普通車で、1 年度の値です。自社の 1 か月の値と、車種の構成が違えば、そのぶんずれます |
| 積載効率 | 38.97%（営業用トラック、2025 年度）。画面の右には、同じ年度の営業用普通車の 39.08% も出ます | 大型の積載率 × 大型の実車率 | 国の値は、輸送トンキロ ÷ 能力トンキロ（距離で重みをつけた比）です。自社の値は、区間ごとの積載率の単純な平均に実車率を掛けたもので、式が違います。範囲も、自社は大型だけです |

比べられるのは実車率です。積載効率は、国の値と同じ式ではないので、並べて見るだけにしてください。自社の値どうしで、月ごとや車ごとに比べるのには使えます。

国の積載効率の目標は 44%（2028 年度）です。

## 費用への換算

右の「費用への換算」に単価を入れると、次の式で出します。空のときは、費用も費用の列も出しません。

| 入れる単価 | 出る費用 | 式 |
|---|---|---|
| km あたり変動費（円/km） | 空車の費用（月の合計と、表の列） | 空車の km × 円/km |
| 時間あたりの費用（円/時） | 30 分以上の停車の費用（月の合計と、表の列） | 30 分以上の停車の合計時間 × 円/時 |

- 単価は、燃料・高速・タイヤなど、自社で決めた値を入れてください。全角の数字（`３０`）も読みます。マイナスや数でない文字を入れると、欄の下に理由を出し、費用は出しません。
- 式の km と時間は小数 1 桁で出し、その表示どおりに掛けた値を円として出します（例: 空車 11,368.7 km × 30 円/km = 341,061 円）。表の「空車の km」も同じ丸めです。
- 表の「（主な行き先）での 30 分以上の停車」の列と「停車の費用」の列は、主な行き先での 30 分以上の停車だけです。月の合計は、すべての地点の 30 分以上の停車です。数が違うときは、表の下に両方の回数を 1 行で出します。
- 空車の km が見えても、帰り荷があるかは別の話です。費用は削減額の約束ではありません。

### 曜日の表の曜日

曜日の表（結果の `table`、`pair_table`）の曜日は、次の決め方です。

- 行きの便は、出た日の曜日。
- 帰りの便は、直前の行き（同じ車で 2 日以内）を出た日の曜日。同じ運行の行きと帰りが同じ曜日に入ります。
- 直前の行きが配車表に無い帰りは、その帰りの便自身の日付の曜日で数えます（前の日の曜日にはしません）。休みの日の次の日に出た帰りが、休みの曜日に入ることはありません。

## 気づき

6 つの規則で出します（最大積載量を超える重さの記録があるときだけ、規則 7 を足します）。各気づきに、根拠の行（元のファイルの何行目か）と、次の一手があります。画面には「規則 1」のような番号ではなく、「同じ曜日の帰りがいつも空」のように中身の分かる名前を出します。自社のファイルの気づきの文には、ファイルに書いてあった地名のまま（「江東区辰巳」）を使います。

| 規則 | 条件 |
|---|---|
| 1 | 同じ区間・向き・曜日の便が 4 便以上あり、3/4 以上が空車 |
| 2 | 空で走った区間がある（便数と距離） |
| 3 | 同じ地点での 30 分以上の停車が月 5 回以上（デジタコのある車の記録だけ） |
| 4 | 拘束時間が原則の 13 時間を超えた日がある（デジタコの記録から数えた目安） |
| 5 | 車両総重量 8t 以上か最大積載量 5t 以上として登録された車に、重さの記録が無い（車両の登録を読み込んだときだけ） |
| 6 | 実車か空車かが不明の区間が 15% 以上 |
| 7 | 積んだ重さが最大積載量を超える記録がある（積載率に入れていない件数。無いときは出ません） |

規則 1・2 と、画面の表は、区間を実際の発地と着地の組（例: 名古屋 → 加古川、大井 → 加古川）で数えます。「着地が車庫なら帰り」とは決めないので、遠くからの空車の帰りが、同じ区間にまとまりません。組ごとの集計は、結果の `pairs`（組・便数・空車の便数・空車の km・車格・曜日別）と `pair_table`（組 × 曜日）にあります。地名は、政令指定都市の区まで残します（名古屋市港区）。

「帰り便の下書きにする」を押すと、自社のファイルを見ているときは、気づきに当たる空車の帰りの区間の発地・着地（市区町村）と、出発の曜日・時刻を、帰り便の登録の欄に入れます。日付は、今日から先でいちばん近いその曜日です。値段・車種・荷の条件は、欄で確かめてから登録してください。架空の便 T7 の説明は、サンプルのときだけ出ます。

## 空車の記録から荷主への相談文を作る（帰り便の提案）

自社の運行の画面（`#v=own`）と 1 枚版のページの上のほうに、「運送会社の方: 空車の記録から荷主への相談文を作る」の欄があります。実在の荷主を探す機能ではなく、相談する相手の種類と条件を絞り、人が編集する文面を作ってコピーするだけです。メールやチャットの送信、連絡先の検索、予約、発注はしません。通信もしません。

### 流れ

1. 最初に「架空のサンプルで試す」か「自社の運行記録を読み込む」を選びます。CSV を読み込めなかったときは、理由をその場に出し、サンプルには切り替えません。
2. 画面の上に、データの種類（架空のサンプル / 自社のファイル）、期間、対象の区間が出たままになります。
3. 最初の結果は「どの曜日に、何便中何便が空車だったか」です。分母と不明の便数は、根拠を閉じていても見えます。
4. 「集計の根拠を見る」で、1 便ごとの元の行・区間・使った日時・空車の区分・距離と、それぞれの出どころ（デジタコ・配車表・推定・不明）を見られます。
5. 「提案する荷主と条件を選ぶ」で、荷主の種類（関西向けの商品を出す荷主 / 通い箱・パレットの返送を検討する荷主）、積込と受取の条件（未確認・適合・不適合。初期は未確認）、社内の採算（任意）を決めます。
6. 「交渉文の下書きを見る」で、文面を編集し、「文面をコピー」で写します。

### 数え方

- 復路の候補は、選んだ発地から出た復路の便すべてです。そのうち、着地が記録にある便だけを「区間確定」とします。着地がない便は候補の母数には入れますが、「加古川に着いた便」とは数えず、文面の根拠にもしません。サンプルでは、候補 53 便（空車 20・実車 25・不明 8）、区間確定 45 便（空車 20・実車 25）です。
- 曜日は、復路の便が実際に出発した日時から求めます。前日の往路の曜日（`cycle_wd`）は使いません。実際の出発時刻が記録にない便は、復路の記録日の曜日で数え、時刻は不明と表示します（サンプルでは区間確定 45 便のうち 27 便）。
- 割合には便数を添えます。「ほかの曜日」の割合は、空車・実車が判定できた便だけが分母で、不明の便は含めません（サンプルでは 40 便中 15 便）。
- 空車の走行距離は、既に走り終えた距離です。帰り荷が見つかっても走行距離がそのまま減るとは限らないので、削減した距離や金額には換算しません。距離が記録にない便は 0 km にせず「不明」にします。
- 計算は `web/own_calc.js`（`returnTrips` `returnTarget` `returnPairs`）と `src/shipcompare/own.py`（`return_trips` `return_target` `return_pairs`）が同じ結果になります（`tests/test_v44_negotiate.py` で突き合わせます）。
- 空車を根拠にした提案は、区間確定の空車が 1 件もないとき作れません。その旨と、確かめる元の資料（配車表の着地の欄、デジタコの実車・空車の区分と到着の時刻）を表示します。

### 条件と文面

- 条件は「記録から分かること」（自社の記録。相手の事情ではありません）と、「人が確認した結果」を分けて持ちます。記録だけで「適合」にはなりません。
- 未確認の項目は、文面では相手への質問になります。不適合が 1 つでもあると「保留」か「見送り」になり、通常の提案文は作りません。保留では、再確認する内容を選ぶと、その確認だけの文面になります。
- 商品の輸送と通い箱・パレットの返送では、質問が違います。返送は、種類、数量、所有者と返却先、積み重ねの可否、回収・受け渡しの方法を聞きます。特定の種類なら必ず積めるとは判定しません。
- 金額は任意の社内欄です。空欄は 0 円にしません（0 円は 0 と入れます）。単位（1 件・1 便）と税込・税抜がそろい、費用の範囲を確認していなければ、差額は出しません。仮の追加利益＝希望見積額−確認した追加費用で、0 円以下なら見送りです。運行全体の利益ではありません。金額は文面に入れません。
- 社内の根拠の欄は、文面とは別の場所にあり、コピーされません。車番、運転者、元のファイル名と行、ほかの地点名、会社名、社内の件数・距離、入力した金額が文面に入ると、コピーを止めます。
- 手で直した文面は、条件を変えても、画面を描き直しても上書きしません。変えた条件は「文面に未反映の変更あり」と知らせます。「作り直す」は、直した内容が消えるので、画面の中で確認してから置き換えます。「条件に戻る」は文面を残したまま条件の画面へ、「最初の画面に戻る」は最初の選択の画面へ戻ります。
- コピーは、画面にある編集後の文面が対象です。ブラウザが許可しないときは、文面を選択状態にして、手でコピーする案内を出します。

これは過去の記録の集計です。今予約できる便、今後も同じ曜日に空く保証、受注や削減効果の見込みではありません。サンプルは架空の運行記録です。

## 外に送らないことの確かめ方

ブラウザの開発者ツールの「ネットワーク」を開いたまま CSV を落としてください。取り込みの前後で、`/api/` へのリクエストは増えません。列の対応づけも、Claude などの外部のサービスには送らず、列名の辞書と値の形だけで決めています。

## 例のファイル

### 例のファイルとサンプルの数字の違い

画面の「自社の運行」のサンプルは、同じ架空の会社の記録を、地点の別名「辰巳 → 江東区」を最初から入れて作った固定の値です。`examples/own/` を落としただけでは、別名の前提（辰巳 → 江東区）が入っていないので、数字が少し違います。

| 状態 | 実車率 | 理由 |
|---|---|---|
| 画面のサンプル | 77.6% | 別名を入れて作った値。デジタコの無い区間の距離は、道路の距離（OSRM）の推定 |
| 例のファイルを落としただけ | 76.9% | 「辰巳」が地図に置けない地点のまま。距離の推定が取れない区間がある |
| 「辰巳」に「江東区」を入れて「地図に置く」を押したあと | 77.7% | 別名の前提はサンプルと同じ。距離の推定が、直線距離の 1.25 倍（ブラウザの中の簡易な見積り）で、サンプルの道路距離とわずかに違う |

区間の件数（107）と、実車・空車・不明の件数（69・20・18）は、どの状態でも同じです。

## サーバーなしで使う 1 枚版（`web/own_lite.html`）

配車担当・運行管理者が、サーバーを起動せずに自社の運行を分析するための 1 枚のページです。`web/own_lite.html` をダブルクリックして開くか、公開された URL を開き、配車表とデジタコの CSV を落とします（「サンプルで試す」で架空の例も見られます）。計算はすべて自分のブラウザの中で行い、通信はしません。

- 出るもの: 実車率・大型の積載率・積載効率（件数と式つき）、不明を空車として数えた場合の数字、区間 × 曜日の表（空車の多い順）と曜日ごとの空車 km のグラフ、気づき、確認が必要な項目（年・列の役割・最大積載量などを選ぶと計算し直します）、読めなかった行と直し方。
- そのまま使えるもの: 求荷求車に貼る【求荷】の文（区間ごと）、明日の空きから作る文、帰り荷 1 便の売上の目安（標準的運賃の表に当てた目安で、相場ではありません）、荷待ちの下書き（「荷待ち協議の書面」の貼り付けにそのまま貼れます）、数字と気づきの文、1 ページの印刷。
- 月ごとの保存: 数字の要約・地名の対応・確認の決定・列の役割だけをこのブラウザに保存し、前の月があれば並べて出します。CSV の中身は保存しません。
- 限りがあること: 地図は出ません（地図は完全版の画面にあります）。実在の会社の配車表・デジタコでは確かめていません。
- 作り直し: `uv run python tools/build_own_page.py`（`web/own_calc.js`・`web/own_month.js`・`web/negotiate.js` を埋め込みます）。

## 売上の目安と停車の費用の範囲（SPEC §46）

- 帰り荷の売上の目安は、車庫に向かう帰りの空車だけを数えます。ほかの空車（遠くの発地からの空車、車庫を出る向きの空車）は数えず、画面に便数と km を書きます。空車の費用は全部の空車で計算するので、範囲が違います。
- 停車の費用は、デジタコの停車の記録があるときだけ出します。配車表だけのときは、0 円と書かずに「停車の記録が無いので出していません」と書きます。
- 単価に現実の範囲を超える値（円/km で 1,000 円超、円/時で 100,000 円超）を入れると、計算は止めずに単位を確かめる文を出します。
- 「明日の空きから作る」の日付の初期値は、配車表で車が動いている曜日（動いた日がいちばん多い曜日の半分以上ある曜日）の、今日の次の日から数えた最初の日です。日曜など全車が休みの曜日は飛ばします。
- 区間 × 曜日の表の向きは「車庫から」「車庫へ」です。車庫は推定した地点を表の上に書きます。曜日は、その往復が車庫を出た日の曜日です。
